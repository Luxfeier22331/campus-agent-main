## Sampling Rate

- **After every task commit:** Run the smallest matching `uv run --all-packages python -m pytest ... -q` loop for the touched contract, supervisor, specialist, or eval files.
- **After every plan wave:** Run the full suite command.
- **Before `$gsd-verify-work`:** Full suite must be green.
- **Max feedback latency:** 30 seconds on the task loop / 60 seconds on the full gate.
