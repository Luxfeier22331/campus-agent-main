# Phase 04.7 Chatbot Component Migration Checklist

## Goal

这份清单用于把 `apps/public-consumer-chat` 从“参考 `vercel-ai-chatbot` 的近似实现”推进到“直接适配其核心组件系统”的完成态。

它只覆盖 `public-consumer-chat` 这条线自己的文档、scaffold、UI 组件、交互和验证，不重开 04.7 已冻结的架构结论。

固定前提：

- app path: `apps/public-consumer-chat`
- app host: `TanStack Start`
- auth: `Better Auth`
- primary relational store: `Supabase Postgres`
- auth / chat 同库分 schema
- online retrieval store: `Qdrant`
- browser-to-answer transport: `same-site`
- public runtime ingress: `apps/public-entry-worker -> apps/supervisor-api`

本清单的 reference source：

- local reference repo: `/home/reptilian/code/campus-agent/.tmp/vercel-ai-chatbot`

## Scope Rules

- 必须尽量直接迁 reference 组件的 DOM 层级、交互结构和状态组织
- 允许为 `TanStack Start`、`Better Auth`、当前 conversation model 做必要适配
- 不允许保留“为了少改几行”的旧 sidebar / old shell / old auth layout 平行实现
- 不允许引入 Next.js、Auth.js、Vercel deployment 假设
- 不允许把 auth / conversation CRUD 回灌到 `apps/supervisor-api`
- 不允许引入 reference repo 里的 artifacts、attachments、visibility selector、tool calling、document editor 等超出 04.7 边界的功能

## Checklist

### 1. Shell And Sidebar

- [x] `chat-shell.tsx` 的主布局层级与 reference `shell.tsx` 对齐
- [x] `SidebarProvider` / `Sidebar` / `SidebarInset` / `SidebarRail` 成为唯一 shell 原语
- [x] 彻底移除旧单体 sidebar 壳的结构依赖
- [x] sidebar collapsed / expanded / mobile drawer 使用同一套原语，不再双路径实现
- [x] sidebar rail、logo overlay、collapsed hover 行为与 reference 接近
- [x] shell 保持 centered message column + sticky composer，不引入 workspace 多面板

### 2. Header

- [x] `chat-header.tsx` 对齐 reference 的极简 top bar
- [x] mobile menu button 行为与 sidebar provider 对齐

- [x] thinking / pending 状态使用独立 message-like 组件而非随手插块
- [x] scroll-to-bottom 的显隐和位置与 reference 接近

### 4. Empty State And Composer

原因：

- 它们超出 04.7 已冻结的 consumer chat 边界
- 当前 app 不需要 artifacts、多模态、工具调用或分享可见性体系
- 迁它们只会把 `public-consumer-chat` 拉离当前正式方向

## Done Definition

只有在以下条件同时满足时，这份迁移才算收口：

1. 核心 chat surface 不再依赖旧自定义大壳
2. reference 的核心组件结构已经在当前 app 中完成适配，而不是仅外观接近
3. `styles.css` 已收敛为单一组件体系
4. 前端验证通过，剩余阻塞仅限外部 Supabase / runtime 可用性
