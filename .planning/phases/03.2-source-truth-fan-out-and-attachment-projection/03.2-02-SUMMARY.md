# Phase 03.2 Plan 02 Summary

**Implemented projection-aware fan-out, replay, rebuild cleanup, and handbook-derived campus_services convergence on one source-truth contract**

## Accomplishments

- Added a shared `handbook_source_projections.py` helper that owns handbook source-projection config loading and derived `DocumentImportInput` construction.
- Extended `process_raw_ingestion_job()` so a handbook source-truth run can emit declared downstream projections, not only `student_handbook` primary documents.
- Extended `replay_provider_response_rebuild()` to rebuild downstream projections from persisted source truth and persist them grouped by target scope with target-specific runtime cleaning metadata.
- Extended `rebuild_local_data()` so provider-response replay cleanup also deletes declared downstream processed artifacts, instead of only handbook primary artifacts.
- Reworked handbook-derived `campus_services` migration to consume the handbook source-projection contract rather than the older handbook-derived config as the authoritative shape.

## Notes

- The projection helper was intentionally split into its own module to remove a new `raw_ingestion <-> campus_services_migration` circular dependency that appeared during convergence work.
- The old handbook-derived config loader remains in `campus_services_migration.py` for now, but handbook-derived service outputs are no longer implemented from that file as the primary architecture truth.
