# Phase 4 Plan: Resolver And WorkflowPlan Compilation

## Goal

Compile `CapabilityPlan` into executable `WorkflowPlan` by resolving artifact producers and
dependencies.

## Tasks

1. Implement resolver in Go supervisor runtime.
2. Resolve required artifacts to producer steps using the artifact registry or a validated
   derivative.
3. Validate opening gates, allowed agents/tools, source truth, freshness posture and budget.
4. Emit stable fail-close reasons for missing/closed/ambiguous/cyclic/ineligible artifacts.
5. Add success tests and one test per fail-close reason.
6. Add a guard that resolver has no provider/model dependency.

## Exit Criteria

- Selected notice follow-through can be generated by resolver.
- Resolver is deterministic and does not call model/provider code.
