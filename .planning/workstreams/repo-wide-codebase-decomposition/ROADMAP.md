# Roadmap: Repo-wide Codebase Decomposition

## Overview

这条 workstream 只负责 repo-wide handwritten code/test decomposition。
它不替代任何业务 workstream，也不接受“顺手修功能”的 scope 漂移。

## Phases

- [x] **Phase 1: Inventory Freeze And Decomposition Contract** — 冻结 repo-wide oversized handwritten code inventory、phase mapping、verification expectations 与 non-goals，确认这条线只拆 hand-written code/test，不动 vendor / generated / lockfiles。
- [x] **Phase 2: Ingestion Core Handbook And Pipeline Decomposition** — `handbook_cleanup.py`、`process.py`、`raw_ingestion.py`、`local_rebuild.py`、`campusrag_ingestion_support.py`、`chunking.py`、`handbook_chunking_validation.py` 均已降到阈值内并完成 facade-oriented split。
