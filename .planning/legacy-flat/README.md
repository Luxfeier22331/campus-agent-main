# Legacy Flat Planning Archive

这里保存迁移到原生 GSD workstreams 之前的 flat `.planning` 资产。

## 用途

- 保留旧 milestone / phase 历史叙事
- 保留已经完成的 flat-mode `phases/`、旧 `STATE.md`、旧 `ROADMAP.md`、旧 `REQUIREMENTS.md`
- 为仍需追溯历史 phase 计划的文档提供稳定 archive 路径

## 非用途

- 不再承载当前执行真相
- 不再作为 workstream 认领入口
- 不再要求把新的 active/deferred/backlog 状态写回这里

## 当前入口

- repo 级当前真相：`../PROJECT.md`
- repo 级 workstream registry：`../WORKSTREAMS.md`
- 单条线当前状态：`../workstreams/<slug>/STATE.md`
