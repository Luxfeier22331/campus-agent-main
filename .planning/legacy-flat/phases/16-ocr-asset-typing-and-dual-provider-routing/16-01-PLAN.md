# Plan 16-01: Freeze OCR 资产类型真相与路由契约

## Objective

把 OCR 路由所需的资产类型真相收口到 raw layer，形成后续 compare、fallback 和 conditional canonical admission 的共同前提。

## Tasks

1. 扩展 raw asset registration / registry truth，补齐 `content_type`、扩展名、字节数、页数、图像尺寸、`asset_kind`、`asset_subkind`、`classification_confidence`。
2. 明确资产类型推断生命周期：
   - 注册时的轻量推断
   - provider compare 后的可选 refine
   - canonical import 前的最终 routing decision
3. 复用已存在的 MIME / 扩展名推断逻辑，移除“raw asset 一律是 PDF”的隐含假设。
4. 冻结 provider-neutral routing contract，确保类型结论只影响 provider 选择，不污染 source truth / document truth / retrieval truth。

## Verification

- focused tests for raw asset registration and registry round-trip
- focused tests for MIME / extension inference and type classification
- doc review against `docs/architecture/data-plane-architecture.md`

## Acceptance Criteria

- raw-asset layer能稳定区分 PDF、图片以及后续 Office 文档候选
- routing decision 所需字段不再依赖 ad hoc 文件名猜测
- `packages/contracts`、retrieval serving truth 和 source truth 没有被 provider-specific 字段污染
