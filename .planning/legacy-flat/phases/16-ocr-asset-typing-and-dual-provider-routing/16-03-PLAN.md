# Plan 16-03: 实施条件式 canonical 路由与 fallback 边界

## Objective

在不放宽 serving scope、也不污染 source truth 的前提下，落地“MinerU 条件式 canonical + Paddle fallback”的第一版执行策略。

## Tasks

1. 冻结第一版 routing matrix：
   - text-dominant PDF -> MinerU candidate
   - long structured PDF -> MinerU candidate
   - wide / colored / merged-cell complex table image -> MinerU candidate
   - simple table image -> Paddle keep/fallback
   - spatial image -> deferred / non-canonical OCR
2. 明确 provider output 存储与 canonical source truth 的关系，保证 downstream 只消费 canonical source truth。
3. 保持当前 Paddle canonical path 可回退，直到 tranche validation 通过新的 admission gate。
4. 把 Office 文档接入标记为 follow-up，前提是 raw asset registration 与 downstream normalization 不再假定 PDF-first。

## Verification

- focused tests for routing policy selection
- replay/import smoke on at least one PDF family and one image-table family
- doc review against `docs/environment/README.md` 和 current compare env templates

## Acceptance Criteria

- repo 拥有清晰的第一版 routing matrix
- 任何 MinerU canonical admission 都是显式 allow，而不是 provider default 漂移
- Paddle fallback 在 simple-table 风险未关闭前继续可用
