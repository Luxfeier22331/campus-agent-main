## Accomplishments

- Replaced rag-only delegation schema names with a typed shared `SpecialistRequest` / `SpecialistResponse` envelope plus `RagRequestPayload`, `AvailabilityCheckPayload`, `RagResultPayload`, and `AvailabilityObservation`.
- Updated `rag-specialist` and the answer API shell to consume the new envelope while keeping `/api/v1/answer` locked to the rag-default `regulations/student_handbook` request shape.
- Refactored `supervisor-core` to route by explicit specialist target, use a target-keyed delegate map, and keep the existing `context -> routing -> delegation -> policy -> response assembly -> audit` pipeline.
- Locked the new boundary with supervisor regressions proving availability routing does not inspect `KnowledgeScope`, missing availability delegates fail clearly, and non-rag completed responses keep `source_doc_ids == ()`.
