# Plan 10.5-02: Clean Up Stable-Reference-Like Serving Assumptions

## Objective

Replace the remaining `official_web/muc_public_pages`-only serving assumptions
with a reusable stable-reference-like helper that works for both the mixed
bridge and the new `stable_reference` scope.

## Tasks

1. Add ingestion-core helper(s) that identify stable-reference-like official-web profiles and collections.
2. Reuse the helper in retrieval ranking, document-support queries, low-signal fail-close, diversity policy, specialist answer shaping, no-answer copy, and confidence logic.
3. Add eval scope helper(s) so future split-scope benchmarks do not depend on one hardcoded official-web collection.
4. Add regression tests for `stable_reference` while preserving existing `muc_public_pages` behavior.
