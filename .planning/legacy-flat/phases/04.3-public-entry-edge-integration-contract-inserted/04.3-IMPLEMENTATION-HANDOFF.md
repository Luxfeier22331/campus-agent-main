# Phase 04.3 Implementation Handoff

## What Plan 01 Froze

Plan 01 通过 `docs/architecture/cloudflare-public-entry-integration-contract.md` 冻结了以下 public-entry contract truth：

- public entry integration 只存在于 `Cloudflare -> apps/supervisor-api` runtime seam
- request-id / trace 是 runtime-level correlation context，不是 app-layer actor identity
- cache、body-size、timeout、streaming、health/readiness 都是 runtime seam concern
- 这些 edge/runtime concern 不能下沉进 `packages/*`

## Implementation Rules Table

| Concern | Frozen rule | Still deferred |
| --- | --- | --- |
| forwarding | public entry still fronts `apps/supervisor-api` only | concrete route/config implementation |
| request-id / trace | runtime may consume correlation metadata only as runtime context | tracing vendor, exact propagation mechanism |
| cache / body-size | public-entry posture stays explicit and conservative | exact cache and size settings |
| timeout / streaming | timeout budget and streaming remain runtime-seam assumptions | concrete timeout numbers and streaming implementation |
| health / readiness | health/readiness terminates at the public runtime seam | exact endpoint and probe configuration |

## Rules That Must Survive Implementation

- public entry 继续只 front `apps/supervisor-api`
- implementation stays at the runtime seam
- no edge concern is pushed into `packages/*`
- request-id / trace must not be treated as `SupervisorRequest.actor`
- no implementation note may claim to solve retrieval ACL or audit closure

## Explicit Deferred List

The following remain deferred after 04.3:

- concrete Cloudflare config
- tracing vendor integration
- auth / actor mapping
- retrieval ACL
- audit closure
- package-level contract changes

## Minimal Checklist For Downstream Work

- [ ] public entry still fronts `apps/supervisor-api`
- [ ] implementation remains runtime-scoped
- [ ] forwarding rules do not become package contracts
- [ ] trace correlation remains distinct from actor identity
- [ ] cache/body-size/timeout/streaming stay documented at the edge/runtime seam
- [ ] no edge/provider concern is pushed into `packages/*`
- [ ] no downstream implementation claims to close Phase 5 governance scope

## Summary

04.3 已经把 public-entry integration contract 收口完成。后续真实实现只应围绕 runtime seam 落地，不应再回头争论 forwarding、trace、timeout、health 这些 concern 到底属于 edge 还是 package，也不应把 tracing/correlation 误写成 app-layer identity。
