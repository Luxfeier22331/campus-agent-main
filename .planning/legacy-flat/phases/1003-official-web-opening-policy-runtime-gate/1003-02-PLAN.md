# Plan 1003-02: 收口 routing、evidence 与 eval gate

## Objective

把 `official_web` 新闻面从“文档里说要分开”推进到“routing / evidence / eval 上可验证地分开”，但仍保持当前分支不开放 runtime。

## Scope

- supervisor / specialist 对新闻 intent 的 routing contract
- `article_detail` / `listing_page` evidence policy
- official-web eval / live-gate rules

## Tasks

1. 固定三类 query intent：
   - 稳定说明
   - 近期新闻
   - 历史新闻
2. 固定 evidence rule：
   - `article_detail` 为默认主证据
   - `listing_page` 只做 discovery / freshness trigger / navigation fallback
3. 为“今天 / 最新 / 最近”定义 freshness-gated failure contract：
   - local fresh enough 才可答
   - 否则 live search 或 fail-close
4. 增补 eval / deterministic gate，覆盖：
   - recent-news ask
   - stale local index ask
   - explicit historical ask
   - archive must not backfill recent ask
5. 确认 `news_archive` 只在显式历史 intent 下参与候选集合。

## Verification

- targeted policy/eval review against `1003-RESEARCH.md`
- qrels / live-gate inventory review
- docs and test case review in official-web worktree

## Acceptance Criteria

- routing contract 不再把稳定说明、近期新闻、历史新闻混成一个 query surface。
- `listing_page` 不能再在未显式降级的情况下充当新闻正文证据。
- eval 能检测 archive backfill、stale-answer、detail-missing 等错误路径。

## Out Of Scope

- query-serving runtime 打开
- 前端新闻呈现
- 具体 live-search provider 接入
