# Plan 1003-03: 定义独立 worktree acceptance 与 handoff contract

## Objective

为 `official_web` 独立 worktree 固定一份 acceptance / handoff contract，避免 future `fresh_news` / `news_archive` 工作再次以局部 seed 结果冒充 runtime opening readiness。

## Scope

- independent-worktree acceptance checklist
- required artifacts / evidence
- current branch 与 independent worktree 的边界说明

## Tasks

1. 固定独立 worktree closeout 前必须存在的 artifact：
   - opening criteria checklist
   - metadata coverage summary
   - duplicate-collapse posture
   - eval / live-gate artifact
2. 固定当前分支与独立 worktree 的责任边界：
   - 当前分支只维护长期 policy truth
   - opening execution 与 acceptance 在独立 worktree 完成
3. 明确什么不能作为 handoff success：
   - seed import/release
   - isolated qrels hit rate
   - 单次本地问答样例
4. 为未来 promote 到 active rollout 的条件建立 checklist，与 `.planning` 同步。

## Verification

- checklist review against `1003-RESEARCH.md`
- `.planning/PROJECT.md` / `.planning/STATE.md` boundary review
- official-web handoff/reference doc review

## Acceptance Criteria

- official-web 独立 worktree 的 closing artifact 有统一口径，不再靠对话内口头约定。
- 当前分支不会因为局部 news baseline 成功就错误宣称 runtime ready。
- promote 到 active rollout 前的 prerequisites 清晰可审计。

## Out Of Scope

- 真正执行 opening smoke
- runtime rollout
- archive/operator UX 细节
