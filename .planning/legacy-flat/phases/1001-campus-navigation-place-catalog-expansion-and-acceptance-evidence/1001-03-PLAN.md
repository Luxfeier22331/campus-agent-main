# Plan 1001-03: Define and close place-finding staging/manual acceptance evidence

> Deferred on 2026-04-14. 当前产品路径已明确暂不支持校内导航；本计划等待地图实际上线后，再从 backlog `999.2` 恢复执行。

## Objective

把 place-finding 的 acceptance 从“后面再 smoke”升级为明确执行合同：固定 query inventory、expected outcome、artifact path 与人工验收项，并在条件允许时完成一次真实 evidence closeout。

## Tasks

1. 定义第一批 acceptance query inventory：
   - direct campus-qualified building lookup
   - ambiguous cross-campus same-name lookup
   - service-point lookup
   - unknown-place rejection
2. 为每类 query 固定期望终态与最低 evidence 要求：
   - `completed`
   - `needs_clarification`
   - `no_answer`
3. 明确 artifact 形态：
   - staging smoke summary
   - 必要截图 / 结果摘录
   - query-to-expected-outcome checklist
4. 在 staging 条件可用时执行一次真实 closeout，并把 evidence path 回写到 planning / docs truth。

## Verification

- query inventory review against Phase 1001 first-batch seed
- smoke checklist review against `apps/app-api` / `apps/public-chat-web` current place-card behavior
- when executed: real staging/manual artifact inspection

## Acceptance Criteria

- place-finding 有独立的 acceptance checklist，而不是混在历史 Wave E 叙述里
- 每类关键问句都有明确 expected outcome
- evidence artifact path 可复用、可追溯
- staging/manual acceptance 不再是“默认以后再补”的隐式欠账
