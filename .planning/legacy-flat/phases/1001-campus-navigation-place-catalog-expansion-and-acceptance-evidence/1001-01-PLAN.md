# Plan 1001-01: Freeze authoritative source inventory, verification posture, and ambiguity families

## Objective

把 Phase 1001 的 place-catalog 扩面前提冻结为可执行 truth：明确 authoritative source、第一批 candidate inventory、`verification_state` 使用规则，以及必须进入 clarification 的同名地点 family。

## Tasks

1. 以中央民族大学官方 `校园地图` / `校园导游` 页面为基础，整理海淀校区与丰台校区第一批高频 place candidate inventory。
2. 明确每类 candidate 的 admission posture：
   - 已有受控 geometry，可直接进入 seed
   - 名称和校区已确认，但 geometry 仍需二次来源或人工校准
3. 固定本 phase 的 `verification_state` 规则，避免 silent confidence：
   - 已人工审阅且几何受控的行
   - 已人工审阅但仍待 field / geometry check 的行
4. 明确必须 clarification-first 的同名 family，并锁定相应 regression expectation：
   - `图书馆`
   - `北门`
   - `南门`
   - 以及首批 inventory 中新增的其他跨校区同名点位
