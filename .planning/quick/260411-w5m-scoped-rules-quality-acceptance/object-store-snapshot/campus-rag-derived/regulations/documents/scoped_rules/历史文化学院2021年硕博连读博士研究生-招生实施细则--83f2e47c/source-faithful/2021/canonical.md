# 历史文化学院2021年硕博连读博士研究生 招生实施细则

根据教育部有关文件精神及《中央民族大学2021年硕博连读博士研究生招生工作》要求，我院在2021年博士研究生招生中继续实行硕博连读招生。

一、硕博连读研究生招生的专业及导师

招收硕博连读的专业和导师详见2021年硕博连读博士研究生招生专业目录。

二、硕博连读研究生选拔对象

我校全日制非定向、优秀的三年级学术型硕士研究生。

三、学生申请硕博连读研究生的条件

（一）拥护中国共产党的领导，维护国家统一和民族团结，愿意为社会主义现代化建设服务，品德良好，遵纪守法，遵守学校的各项规章制度，没有学术不端行为，没有受过任何处分。

（二）已完成规定的课程学习和考核，专业必修课和专业选修课成绩不低于80分，其他课程成绩不低于70分。通过英语六级≥426分，或小语种四级以上（含）。

（三）具有较强的科研能力和创新精神，具有严谨的科学研究态度与作风，博士申请专业与硕士学位专业为相同或相近专业，博士阶段的研究计划应有一定的前瞻性和创新性。

（四）硕士研究生培养阶段至少须有一项高水平科研成果，包括已发表的学术论文或科研成果奖励等。科研成果至少满足下列要求中的一项：

1.在核心期刊上发表专业学术论文1篇以上（含）；

2.普通期刊发表专业学术论文2篇论文以上（含）；

（五）学术论文均指以第一作者发表的研究型学术论文，不包括综述性论文、会议报道、书刊评介、纪念文章。学术论文须正式发表，不能是用稿通知。

（六）至少两名所报考学科专业领域的教授或相当专业技术职称的专家（非申请人的硕士培养导师和博士申请导师）做出书面推荐。

（七）身体健康，符合教育部《普通高等学校招生体检工作指导意见》体检标准。

四、硕博连读研究生招生的程序

（一）学生申请，时间为2021年1月8日下午5：00前，向学院教学办公室提交纸质版相关材料。

学生依据学校硕博连读申请条件及学院制定的科研成果申报条件向学院教学办提交《中央民族大学硕博连读申请表》、2份《专家推荐信》、成绩单、《开题报告评议书》复印件及其他表现本人学术科研水平的材料。

（二）导师意见：硕士培养导师和博士申请导师分别在《中央民族大学硕博连读申请表》上签署意见，若硕士培养导师和博士申请导师为同一人，还须所报考学科专业领域的另一位正高级专业技术职称专家签署意见。

（三）综合考核，时间为2021年1月11日。

研究生招生领导小组牵头负责组成至少5名博导的综合考核小组，对学生的政治思想表现、专业知识、学术素养、创新精神和科研能力进行考核，重点考察申请人是否“品学兼优”、科研潜能突出，学院学工部门对学生作思想鉴定。

（四）学院审核：学院研究生招生领导小组审核确定硕博连读拟录取名单，并在网站上进行公示，公示期为5天（包含节假日），公示结束后报学校研究生招生办公室复审。

（五）复审公示：学校研究生院对硕博连读拟录取名单进行复审并公示，公示期为10个工作日。

（六）招生报名：公示无异议的学生参加2021年博士生招生报名，录取类别为非定向；具体报名详见研究生院网站上的《中央民族大学2021年博士研究生招生简章》。

（七）录取与后期审查：按2021年博士生招生统一进度进行录取。在硕士生培养阶段，对拟接收的硕博连读研究生进行后期审查，凡有受到纪律处分、提供虚假申请材料或不能按时取得硕士学位者，取消其博士生录取资格。

五、其他说明

（一）硕博连读拟录取研究生需在2021年入学前取得硕士毕业证书和学位证书，否则取消博士入学资格。

（二）硕博连读拟录取研究生无需参加当年度博士研究生的招生考试。

（三）硕博连读研究生占用当年度导师的招生指标。
