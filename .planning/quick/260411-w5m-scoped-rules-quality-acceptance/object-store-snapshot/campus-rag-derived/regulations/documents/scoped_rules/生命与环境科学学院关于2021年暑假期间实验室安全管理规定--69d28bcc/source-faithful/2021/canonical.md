# 生命与环境科学学院关于2021年暑假期间实验室安全管理规定

生环实发【2021】02号

根据学校近期关于加强暑假期间安全稳定的有关指示精神，现将暑假期间（2021年7月16日至8月30日）学院实验室安全管理办法规定如下：

1、任何教师和学生不得私自带领与实验室无关人员进入实验室、学生在实验室不得从事和实验无关的任何活动；

2、认真做好实验室水电等设施的检查及关闭工作，特别注意水、火、电、化学药品的使用安全，严格按照实验室管理的有关规定进行；

3、实验技术人员应切实加强教学实验室放假前检查，做好暑假期间学生使用实验室的安排工作，严格按照仪器设备的操作规程进行；

4、关于科研实验室，由各实验室责任人（教师）负责，认真做好暑假期间实验室安全管理工作，安排好相应的实验研究。假期期间必须由2人以上方可进行实验，实验期间必须有人看守。特别要加强研究生及进行研究训练项目本科生在实验室进行实验研究的安全管理，不在实验室时关闭门窗，严禁在实验室食宿；

5、为了确保实验室安全，暑假期间使用大型仪器设备需提前申请预约，严禁私自使用，请大家做好实验安排。

请广大教师认真按照上述规定执行，切实承担实验室责任人的职责。发现违反规定者，学院将给以批评、通报及有关处分。
