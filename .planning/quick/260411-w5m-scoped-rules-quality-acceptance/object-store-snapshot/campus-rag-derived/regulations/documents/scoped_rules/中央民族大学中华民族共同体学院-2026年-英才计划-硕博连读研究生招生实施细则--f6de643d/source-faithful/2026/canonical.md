# 中央民族大学中华民族共同体学院 2026年“英才计划”硕博连读研究生招生实施细则

一、招生专业

我院中华民族共同体学专业招收“英才计划”硕博连读研究生。

二、选拔对象

我校全日制非定向的学术学位、专业学位（三年制）二年级硕士研究生均可申请。

三、申请条件

（一）坚定对伟大祖国、中华民族、中华文化、中国共产党、中国特色社会主义的高度认同，维护祖国统一和民族团结，遵纪守法，品行端正，无任何违法违纪受处分记录，诚实守信，学风端正。

（二）已完成的专业必修课和专业选修课成绩均不低于85分，其他课程成绩均不低于70分。

（三）遵守学术道德，具备创新精神和培养潜质。

（四）至少有2名所报考学科专业领域的教授或相当专业技术职称的专家（非申请人的硕士培养导师）做出书面推荐。

（五）硕博连读申报的博士专业一般应与硕士就读专业属于同一个一级学科。对于跨学位类型、跨一级学科的申请人，要具备跨学科的潜力和科研能力。

（六）身心健康，身体健康状况符合《普通高等学校招生体检工作指导意见》的相关要求。

（七）硕士研究生培养阶段发表高质量论文或参与省部级及以上课题者优先考虑。

四、招生程序和时间安排

（一）网上报名

1．报名时间：2025年12月10日—2026年1月10日

2．网上报名网址：https://yjszs.muc.edu.cn/（中央民族大学研究生招生平台）

3．网上报名程序

（1）考生登录我校博士报名平台，进行注册。

（2）在网上填报报考信息、上传本人近期正面2寸免冠证件照和相关电子材料。

（3）网上支付200元报名费。网上支付报名费后，无论考生是否参加考试，一律不退还报名费。我校报名费只采取网上支付方式，不接收现场缴费和邮政汇款。

（4）网上报名须提交的电子材料

①网上报名系统中的博士报名表（从网上报名系统直接下载打印）；

②《中央民族大学2026年“英才计划”硕博连读申请表》（模板见附件1）；

③至少有2名所报考学科专业领域的教授或相当专业技术职称的专家（非申请人的硕士培养导师）做出书面推荐。注意：签字部分务必由专家本人签字，务必为正高级（或相当职称）专业技术职称的专家，否则材料审核不合格；

④硕士阶段的成绩单（加盖学校研究生院公章，可使用新研究生系统成绩单彩打）；

⑤在学术期刊上发表的学术论文、重要的获奖证书、课题结项证书扫描件以及其他可以体现申请人科研能力的材料；

⑥个人陈述。个人陈述要使用国家通用语言文字，内容包括学习及学术研究经历、对报考专业及研究方向的认识及个人优势，字数不超过2000字；跨学位类型、跨一级学科的申报人须提供跨学位类型、跨一级学科申报的缘由及攻读博士学位的基础与潜力说明。

⑦研究计划书。研究计划书包括申请人拟在攻读博士学位期间将要开展的研究问题、研究思路、文献综述、理论基础、已有的研究成果、研究内容设计、研究方法及研究创新性等内容，须使用国家通用语言文字写作。

注：材料需由原件清晰扫描为电子版，且按照以下编号排序合并为一个PDF电子文件，加上封面和目录通过报名系统提交。

（二）网上报名注意事项

（1）申请人按照招生专业（研究方向）进行报名，考试类别填写：硕博连读，报考类别：非定向。报名时可填报2位本专业（中华民族共同体学）的意向导师，但不按照意向导师进行排名和拟录取。

（2）申请人报名前务必仔细阅读学校公布的招生简章和学院公布的硕博连读招生通知，确认本人是否符合报考条件。须如实、准确提交报名信息和相关材料，不得弄虚作假。在任何阶段一旦发现不符合报考条件或提交的报考信息不真实，我校将取消其报考资格和录取资格，相关后果由申请人本人承担。

（3）申请人报名时填报的姓名、身份证号必须与身份证件及学历、学位证书上的信息一致，如不一致，须提供相关部门的证明材料，因信息不一致引起的一切后果由考生自行承担。

（三）综合考核。1月底前学院对申请硕博连读的考生进行资格审核，并组织符合条件的申请者进行综合考核。具体综合考核时间、地点安排将另行通知。

（四）学院审核公示。学院研究生招生委员会对符合录取条件的申请人依据最终成绩、思想政治表现、健康状况等按照专业择优确定拟录取名单，并进行公示，公示期为5天。综合考核分数低于60分的考生不予录取。

五、报考说明

（一）“英才计划”硕博连读招生报考阶段只报专业（中华民族共同体学），报名时填报的导师仅为意向导师，不按照意向导师进行排名和拟录取。后续由学院根据申请人导师志愿和学科需要，确定导师。

（二）“英才计划”硕博连读研究生录取类别为非定向。定向就业的硕士研究生不能申请。

（三）“英才计划”硕博连读招生人数占用学院普通招生计划，原则上不超过本专业（研究方向）普通计划招生总数的50%。

六、学制及培养

（一）基本学制为6年（从硕士研究生阶段开始计算），最长学习年限按照《中央民族大学研究生学籍管理办法》执行。

（二）硕士研究生阶段的第5学期进行资格考核，资格考核“合格”者进入博士研究生阶段的学习，享受博士研究生待遇，达到博士研究生毕业要求和博士学位授予标准后，方可毕业，授予博士学位。若资格考核“不合格”，考核小组认为可完成硕士研究生学位学习者，经本人申请，导师同意，由培养单位签署意见后报研究生院审核，审核通过后继续按照原硕士阶段专业进行培养，达到硕士研究生毕业要求和硕士学位授予标准后，方可毕业，授予硕士学位。
