# Agent Note: ADR-0004 评测指标

Status: implemented

## 背景

Agent 可能在工具选择、检索、答案生成或安全处理阶段失败。单一总分无法指出失败边界，预先列出
没有 scorer、观测来源或适用数据集的指标也不能形成可执行评测。

## 决策

评测分别观察：

- 执行结果和工具轨迹；
- 检索相关性与禁止证据；
- 答案质量与证据一致性；
- 安全和明确失败行为。

精确结果、工具名、稳定参数、上下文 ID 和禁止证据优先使用确定性断言。只有需要语义判断时才
使用模型评分，不使用单一总分替代各维度结果。

具体评测任务只选择当前问题需要、具有明确输入和可执行 scorer 的指标。缺失输入和不适用场景由
所属 scorer 直接处理，不建立中央指标准入流程。

可发布的 Langfuse score 由所属实现的代码级 allowlist 校验，不再维护或同步第二份 score registry。
具体 Ragas 指标由实际评测任务和输入决定；空检索是有效样本，缺少 reference 的 context 指标直接
跳过，实际 scorer 错误才进入评测错误。

本 ADR 不复制完整指标名或承诺未实现评分。评分结果用于质量分析；需要人工校准时由具体评测任务
决定，不自动形成合并或发布结论。

## 未采用方案

- **只发布单一总分**：容易比较，却无法定位工具、检索、生成或安全边界的失败。
- **预先维护完整指标目录与独立 score registry**：便于集中浏览，但没有 scorer 或消费者的指标
  不能形成可执行评测，且会与实现的 allowlist 重复。

## 后果

- 新指标必须具有实际调用方和可执行实现；需要发布到 Langfuse 时再加入所属代码 allowlist；
- 声明为不适用的 case 不伪装成零分；缺少 reference 的 context 指标直接跳过，实际 scorer 错误才
  进入评测错误；
- Ragas 官方指标与仓库确定性断言可以协作，双方不重复实现同一评分器；
- 指标按失败边界组织，不为增加看板数量创建无消费者 score。
