# Agent Note: 文档治理

Status: implemented

## 背景

仓库曾同时保留入口清单、当前说明、计划、审计记录和历史归档。同一事实因此出现多份
版本，过期计划也容易被误读为当前架构。

## 决策

长期文档按读者问题和事实所有者分工，README 只提供入口；一个窄能力能由一篇文档说明时，不建立
架构、合同、数据和操作的重复正文。代码、schema、配置和测试是当前实现来源，人类文档不得把
目标或一次运行结果写成当前事实。

跨分区主题（如校园地图、通知、可观测性）由该主题的所属领域文档承担路由责任，用 `## 相关文档`
章节链接到分散在 runbooks、contracts、data、模块 README 和决策笔记中的相关文档；章节名统一为
「相关文档」，不再使用「相关入口」「相关决策」等异名。面向任务的跨分区入口由
[主题索引](../../../../docs/reference/topic-index.md) 以纯链接聚合，不复制正文。

`docs/runbooks/` 按 owner 或操作对象分组：同组两篇及以上才建子目录并配 README 索引
（release、runtime、observability、ingestion、access），单篇窄能力保持平铺。
runbook 使用边界、前置条件、操作步骤、失败处理、相关文档的章节骨架，「相关文档」必备；
`owner_boundary` 填真实代码边界，不用 `docs/runbooks` 分区名代替——分区目录只是索引，
不承担具体操作的 ownership。既有 runbook 在改动时顺带收敛骨架，不批量重排章节。

[文档规范](../../../../docs/AGENTS.md)维护放置、语言、写作和验证操作规则，贡献指南与文档入口
统一引用它；本笔记保留这些分工的理由。步骤型指南与查询型参考按读者任务组织，避免操作路径被
实现细节打断，也避免参考说明藏在教学步骤中。
普通文档仅承载当前有效事实和约束；计划、执行记录、一次性审计和被取代且无独立理由的正文
由 Git 历史保存，不另建普通文档归档目录。
产品文档中的完成标准描述用户可见行为，不记录某次执行的检查结果；PR 和 CI 记录本次实际检查；
发布记录和 runbook 记录制品进入目标环境后的运行结果。决策笔记只保留长期理由、后果和会影响未来判断的
覆盖缺口，不把一次性命令、请求标识或临时环境观察写入 implemented 正文。
Issue 与 PR 按[贡献指南](../../../../.github/CONTRIBUTING.md)分工：Issue 描述问题和目标，PR 记录实际
改动与验证。旧模板的验收清单和验证计划曾被保留为历史 Issue 门槛；维护时按当前目标修订，
不将 Agent 自拟条款自动当作用户需求。复现环境不决定验证环境，真实环境交付仍按任务本身判断。
提案笔记的章节要求仅约束笔记，不传播为 Issue 或 PR 的默认完成条件。

产品文档中的完成标准属于用户行为合同，不记录某次执行的检查结果；PR 和 CI 记录本次实际检查；
发布记录和 runbook 记录制品进入目标环境后的运行结果。决策笔记只保留长期理由、后果和会影响未来判断的
覆盖缺口，不把一次性命令、截图或临时环境观察写入 implemented 正文。
决策记录采用 Agent Notes，状态、归档和理由保留规则由
[决策笔记树](./2026-09-16-agent-notes-tree.md) 拥有；原 ADR 编号仅作历史标识。

[事故复盘](../../../../docs/postmortem/README.md)是保留历史故障经过的专门分区：记录影响、
故障机制、漏检原因和已落实的修复与验证。它不承载当前产品合同或替代决策笔记；
仅为机制隐蔽、暴露系统性缺口且重新发现成本高的真实故障写复盘，不要求每个 bug 都记录。

本笔记 只记录上述文档边界及其理由，不维护全仓文档清单、当前快照或额外治理扫描器；具体事实仍由
所属文档和可执行来源维护。

## 未采用方案

- **永久保留全部计划和清理记录**：默认分支会成为不可判读的历史仓库。
- **用一个总文档复制全仓库事实**：所有权变化后必然产生第二份过期内容。
- **为每个文档规则增加中央扫描器**：领域语义应由所有者评审或所有者测试负责。
- **将所有历史验收条款原样保留或一律删除**：前者延续无依据的流程门槛，后者丢失真实交付要求；
  按当前目标修订，而非按“验收”或环境名称批量替换。

## 后果

- 新增文档前先确认已有所有者；能更新现有文档时不新增文件。
- 删除重复或过期正文时保留仍有效的事实和直接引用，历史由 Git 记录。
- 文档检查只验证可自动判断的结构不变量；领域事实仍由所属实现和合同验证。
