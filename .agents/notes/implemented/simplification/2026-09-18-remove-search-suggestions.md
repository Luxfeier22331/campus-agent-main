# Agent Note: 移除搜索建议

Status: implemented

## 背景

Gemini 通过统一网关接入，产品不需要 Google 搜索建议。此前应用将供应商 HTML 经 Runtime、
Workflow 和 App API 持久化后用 iframe 展示，增加了与产品目标无关的传递与展示逻辑。
本决定部分取代 [Agent 输入输出](../architecture/2026-07-16-agent-io.md) 中保留搜索建议的选择。

## 决策

- 删除建议组件、消息类型，以及 Runtime、执行控制和 App API 的建议字段与汇总逻辑。
- 保留原生搜索、搜索使用状态、grounding 证据、正文引用与来源卡。
- 历史消息通过已有未知结构化类型过滤逻辑丢弃建议，不迁移或重写存储。

## 未采用方案

- 仅隐藏 UI 能更快消除视觉干扰，但会继续传递和保存无消费者的 HTML，故删除整条建议链路。
- 开关可以恢复展示，但当前没有这项产品需求，故不保留开关或替代组件。

## 后果

Runtime 的严格请求合同不再接受建议字段，发布时需协调 execution-control 与 Runtime，
避免旧执行进程向新 Runtime 发送退役字段。删除不改变工作流 activity 的调度顺序。
已有历史原始 JSON 可以保留，读取后仅返回受支持的消息类型。
验证覆盖供应商建议尾帧中的引用保留、旧消息过滤及运行合同；不新增浏览器测试脚本或 PR CI。
