# Agent Note: Dining SVG 主题颜色

Status: implemented

## 背景

Issue #521 中已发布 SVG 的档口背景固定为白色，前端添加的标签随深色主题变浅，导致未选中档口文字不可辨。

## 决策

Dining SVG 的画布、楼层表面、档口背景、文字和边框使用应用语义 token，继承现有浅色、显式深色与系统深色主题。
领域 renderer 提供浅色 fallback，独立 SVG 仍可查看。Campus Web 在通过现有安全校验后追加主题样式，覆盖已发布 SVG 的固定颜色。
不修改已发布资产、几何、编号或 checksum 校验；新生成资产继续按实际内容计算 checksum。

## 未采用方案

只修改 renderer 可以修复新发布地图，但无法修复用户正在查看的既有资产；因此加载端也必须应用主题。
重新发布全部地图能替换固定颜色，但将界面修复变成内容发布操作，没有必要。

## 后果

既有地图无需重新发布即可响应主题切换，选中、键盘聚焦和搜索 dimmed 继续使用原交互状态。
领域测试检查主题变量和独立 fallback 通过 SVG 清理；本地 MCP 验证浅深色实际计算颜色、选中和搜索状态。
