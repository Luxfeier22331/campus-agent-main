# Agent Note: dining submission interactions

Status: implemented

## 背景

用户投稿编辑、登录续接、详情打开和分享操作存在状态丢失、重复操作或导航中断风险。

## 决策

- 由页面级退出控制统一处理取消、关闭、Escape、遮罩、路由离开和 beforeunload，并以实时编辑状态判断；保存期间拒绝离开。
- 登录弹窗在存在继续操作回调时省略 `callbackURL`，避免 Better Auth 客户端自动重定向；普通登录和验证邮件继续使用原返回地址。
- 投稿列表中文本与缩略图共用详情链接，重试按钮保持链接外部。
- 分享操作复制绝对公开 URL，失败时展示可选中的输入框，不触发导航。

## 未采用方案

不持久化草稿，也不全局关闭 Better Auth 重定向插件，避免扩大认证行为范围。

## 后果

编辑状态可跨背景刷新保留，登录后可直接继续创建或举报；关闭和路由离开会得到一致确认；详情入口和分享反馈在移动端保持可达。覆盖了组件测试、Dining E2E 和本地 MCP 登录及创建旅途。
