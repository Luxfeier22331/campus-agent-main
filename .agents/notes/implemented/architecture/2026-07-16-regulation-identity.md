# Agent Note: 规章标识

Status: implemented

## 背景

如果版本标签属于规章根标识，每次修订都会成为另一份文档，无法可靠表达版本历史、重复来源和
当前有效版本。

## 决策

规章的稳定作品身份与具体版本分开维护：

- 作品身份由规范名称、发布组织和语义范围确定，不包含修订标签；
- 版本身份表达内容、有效日期和修订关系；
- 来源原始标题与产品展示标题分别保留，但不改变作品身份；
- 通知标识和通知发布时间只作为来源信息，不能自动成为规章身份或生效日期；
- “暂行”“试行”、届次和文件编号只有经过明确规则解释后才能成为版本信息。

精确字段、规范化规则和标识生成由当前规章实现、schema 与测试维护。

## 未采用方案

- **将修订标签纳入作品根标识**：每个版本能直接得到独立 ID，却无法稳定表达同一规章的历史。
- **以来源通知标识或发布时间代替规章身份和生效日期**：方便复用来源字段，但两者语义不同，
  不能据此自动合并作品或判断有效期。

## 后果

- 同一规章的多个版本共享作品级标识；
- 展示格式变化不改变身份；
- 多个来源通知可以关联同一规章版本；
- 无法确认作品或版本关系时不得自动合并。
