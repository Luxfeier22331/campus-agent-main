# Agent Note: 通知同 ID 更新与重新发布

Status: implemented

## 背景

用户要求把门户重新发布和内容更新纳入通知处理范围。已核验通知 `358366` 保留同一 ID 和首次发布时间，
当前发布时间从 2026-09-01 10:57 改为 2026-09-29 15:14；外链相同，没有观察到门户正文和附件变化。
这证明发布时间可变，不证明所有编辑都会推进发布时间，也不能证明外链目标内容从未改变。

现有来源合同和维护状态只覆盖固定 source 复用，无法处理已观察到的 `358366` 同 ID 发布时间变化，也无法在正文或资源更新时交接到 publisher。本决策保留通知身份、分类权威、学生端可见性和独立发布职责；更新来源与交接边界由本篇定义。

## 决策

同一 `notice_id` 代表同一条当前通知快照。采集器按内容寻址保存完整来源快照和资源，并在通知行保存 `source_ref`；publisher 只在数据库事务中把当前来源切换到可见标题、发布时间、外链、正文、资源集合和 `published_source_ref`。旧固定 key 仅用于迁移和无引用旧数据兼容。

列表 metadata 变化和每日/每周周期复核会重新请求详情。周期复核覆盖最近 30 天及完整维护区间，失败不推进对应时间戳。资源按 SHA-256 内容寻址，来源资源摘要绑定实际字节；publisher 在资产投影变化时整组替换 `notice_assets`，支持正文删除、内外链转换、资源新增、删除、换序和字节替换。

增量扫描与到期复核先合并候选，每个 ID 在候选处理阶段只处理一次；复核列表 metadata 优先于增量列表和数据库记录，任一来源要求复核即刷新。两种列表扫描及数据库已有通知覆盖保留，任何扫描或处理失败均不推进维护状态。字典在合并后登记，来源引用按本轮候选批量读取，不跨运行缓存。

强制刷新直接下载门户资源，省去随后会被丢弃的旧对象读取；普通资源复用用 HEAD 检查存在性，缺失继续恢复。旧固定路径迁移仍读取字节。已成功读取当前内容寻址快照且结果摘要不变时省去二次探测和写入，库存登记仍执行。每日与每周的资源复核频率保持不变，以发现 URL 未变但字节替换的资源。

publisher 在持有通知行锁的发布事务内比较完整资产投影，集合一致时省去 DELETE/INSERT，变化时仍整组替换；来源字节和摘要校验继续执行。比较包括 ordinal、名称、MIME、大小、摘要及门户附件 ID，不以 source 引用相同代替资产比较。

publisher 的普通候选同时包含未发布且已分类通知，以及 `source_ref` 与 `published_source_ref` 不同的已发布通知。事务用当前 `source_ref` 条件更新，旧来源无法覆盖新来源；分类写回带标题条件，避免旧标题结果覆盖更新后的标题。来源对象、资源对象和 PostgreSQL 不宣称跨系统原子，重跑通过数据库待发布状态恢复。

本地通知同步默认只同步数据库；`--with-sources` 先复制选定日期范围内通知的当前/已发布来源闭包及资源，再导入引用。没有对应对象时不会把远端引用伪装成本地可读来源。预览、OCR、离线分类和附件回填都按数据库来源引用读取，旧固定 key 作为迁移兼容。

索引来源以已发布的图片资产摘要匹配同通知最新完成的 OCR 输入摘要，按已发布资产 ordinal 和页序组装；不按当前采集快照或旧固定 key 推断图片归属。因此内容寻址图片、旧路径下字节一致的识别均可使用，待发布或已删除图片的识别不会混入。内容寻址资源可被不同通知共用，OCR 去重键加入通知 ID，避免任务归属被其他通知占用；旧通知专属路径沿用原去重键。

## 未采用方案

- **只做 inventory upsert**：不能刷新正文、来源和资源，也不能处理内外链转换。
- **固定 key 覆盖加 dirty flag 或整数 revision**：多资源覆盖无法绑定同一快照，内容寻址快照更直接。
- **只依赖 changed IDs 或全库详情扫描**：前者不能跨活动提交恢复，后者没有必要的成本边界；数据库待发布选择和周期复核分别承担恢复与发现。
- **清空 category 或临时下架后重新发布**：会改变人工分类和学生端可见状态。
- **复用时完全信任对象引用、降低每日资源复核频率**：前者可省去 HEAD，后者可减少下载，但分别改变对象缺失恢复和同 URL 字节变化的发现时效，本次只清理冗余 I/O。
- **事件溯源、完整版本历史或 outbox**：当前消费者只需要当前快照到发布的单一交接。

## 后果

通知的发布时间是当前门户发布时间，不代表首次发布时间或正文修改时间。source 与 published source 一致只表示页面投影追平来源，不表示 RAG 已刷新；正文变化沿用现有完整检索刷新。旧通知缺来源或资源摘要时可通过无门户请求的迁移入口补齐，无法核对的对象保留待处理状态。外链目标内容不在采集范围内。
