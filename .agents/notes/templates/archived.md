# 归档结果示例

此文件只展示结果，不用于新建归档笔记。命令会保留原文和原状态，追加日期与可选替代链接：

```markdown
# Agent Note: 原标题

Status: implemented

## 决策

原有正文保持不变，包括历史链接和旧章节。

Archived: 2026-09-16 — superseded by [替代笔记](../../implemented/architecture/2026-09-16-example.md)
```

没有替代笔记时，归档行只有 `Archived: yyyy-mm-dd`。用仓库根目录的归档命令生成，
不要手工复制此示例创建正式归档；具体操作见 [笔记 README](../README.md#归档操作)。
