## 一、培养目标

本专业培养政治立场坚定、综合素质优异、经济理论扎实,具有强烈社会责任感、深厚家国情怀、宽广国际视野,掌握经济学基础、金融学专业知识和相关技能,具备金融前沿学术研究能力和金融创新创业能力,胜任高等院校、国家机关、国际机构和组织以及金融相关领域企事业单位的高素质综合性人才。

## 二、毕业要求

### (一)素质要求

1. 政治素质:牢固树立正确的国家观、民族观、历史观和文化观,对中国共产党和中国特色社会主义高度认同,具有维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。

2. 专业素质:熟悉国家有关金融方针、政策、法律法规,学会用金融学思维审视、分析国家金融安全与金融风险管理等理论与现实问题,学会使用金融学方法和技术,处理政府、企业、金融机构以及中介组织投融资业务。

3. 综合素质:自觉践行社会主义核心价值观,具有良好思想品德、职业道德和社会责任意识,掌握基本的现代信息技术,具有国际视野和跨文化交流能力,热爱劳动,身心健康。

### (二) 知识要求

1. 通识性知识:包括自然科学、社会科学、人文艺术等知识,实现学生“宽口径、厚基础”全面发展。

2. 专业性知识:以经济学理论、方法的学习为主,了解人文社会科学、自然科学、工程与技术科学等相关学科知识,理解金融学的跨学科属性;在经济学大类培养的基础上,聚焦金融学专业知识学习,精通银行、证券、保险等领域的专业知识。

3. 工具性知识:学习文献检索、社会调查、数据处理、学术论文写作等知识,精通现代经济分析方法,熟练运用主流社会经济统计软件。

### (三)能力要求

1. 业务能力:能综合运用金融专业知识,胜任银行管理、证券投资、保险运营、财务会计等各类业务。

2. 科研能力:了解金融学专业及相关领域国内外前沿动态,能综合运用经济学、金融学理论方法,对金融问题进行学理性分析,并提出解决方案或政策建议。

3. 创新能力:养成探究性学习习惯和创新性思维,开展科研训练和竞赛活动,具有良好的实际动手和解决复杂问题的能力,具备“敢闯会创”的创新创业精神。

4. 其他能力:具备较强的中文表达能力、外语能力、人际沟通和团队协作能力以及对计算机、数字信息技术的应用能力等。

## 三、学制、总学分和学位授予

学制:4年

总学分:154 学分

学位授予:经济学学士

### (三)个性化培养

为充分对接学生未来发展、满足学生个性化选择,设置本硕贯通课程、跨学科交叉课程、全球胜任力培养课程和行业领域协同育人课程,学生可根据未来发展意向选择修读相关课程,此部分至少修读6学分。修读建议如下:

拟继续深造学生建议选择修读本硕贯通专业选修课程。免试推荐攻读本校研究生的本科生可提前学习研究生课程,并计入研究生学分。

拟出国学生建议选择修读全球胜任力培养课程,包括全英文科技前沿课程、国际课程、全球胜任力微专业课程,也可通过境外访学进行国际学分转换。

拟就业学生建议选择行业领域协同育人课程修读,针对未来职业选择修读相应的课程。

学生可根据个人发展需要,跨专业选修其他专业设置的专业课程。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,必修10学分。

学年论文一般不少于 8000 字,需有完整的文献综述和研究设计,可作为毕业论文的预研究,四年级开学后提交。

毕业论文一般不少于 10000 字,需使用规范的经济学研究方法,要完成开题报告、毕业论文写作与通过论文答辩。

毕业实习时间累计不少于8周,最终提交实习报告和实习证明。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|≥3|必修|/|
|学年论文(设计)|1(18学时)|必修|/|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分,学校体育运动队队员可免修“大学体育”公共必修学分。
