## 一、培养目标

聚焦国家战略与区域经济社会发展对数学、信息和计算科学人才的需求,以“强基础、宽口径、重实际、创特色”为指导思想,以数据信息处理与人工智能为发展方向,培养具有过硬的政治素质、深厚的家国情怀、宽广的国际视野、良好的综合素养、坚实的数学基础,系统掌握信息科学和计算科学基本理论,拥有较强的数据信息处理、人工智能、信息技术、工程计算中实际问题解决能力,能在科技、教育、信息产业、经济金融等部门从事研究、教学、应用开发和管理工作的应用性或研究型专门人才。

## 二、毕业要求

### (一)素质要求

1. 政治素质:热爱社会主义祖国,拥护中国共产党,具有良好的政治思想素质、道德品质、法治意识、诚信意识和团队合作精神,具有中华民族共同体意识。
2. 思想品德:具有良好的思想品德、职业道德和社会责任意识,具有良好的心理素质和积极的人生观。
3. 综合素养:拥有一定的人文素养和艺术鉴赏能力,熟练使用一门外语,热爱劳动,身心健康,富有创新精神。
4. 职业素养:具有健全的职业人格,热爱数学事业,具备系统的数学思维,掌握科学的数学方法,具有严谨治学、艰苦奋斗、求新务实的精神。
5. 国际视野:了解当前国内外基于研究与实际应用领域的重要数学思想和常用数学方法,具备跨文化沟通能力。

### (二)知识要求

1. 学科基础与理论:具有扎实的数学基础和较强的数学语言表达能力。
2. 专业核心知识:掌握基础数学、计算数学、概率统计以及运筹优化等领域的基本理论与方法,了解数学理论与应用的新发展。
3. 研究方法:掌握数据分析与信息处理、数学建模等方法。
4. 学科前沿:了解当代数学基础研究与应用数学领域的新进展。

5. 跨学科知识:具备较强的计算机运用能力,了解数学理论与方法在其它学科的主要应用。

### (三)能力要求

1. 专业能力:接受系统的数学思维训练,掌握数学科学的重要思想方法和主要研究工具。具有较强的知识更新、技术跟踪及创新能力。
2. 应用能力:熟练掌握计算机常用语言、工具软件及专用软件等技能,具备算法设计、算法分析与编程等知识的更新能力,能运用所学的理论、方法和技能,解决大数据与人工智能、信息技术、科学与工程计算等领域有关的数学建模与计算问题。
3. 科研能力:能够运用数学知识分析和解决实际领域出现的新问题。
4. 团队合作能力:能够在多学科背景下的团队中承担个体、团队成员和团队负责人的任务。
5. 创新能力:具备自主学习、知识更新和终身学习意识,具有理论联系实际的能力,针对实际问题进行分析和研究的创新能力。

### (三)个性化培养

为充分对接学生未来发展、满足学生个性化选择,设置本硕贯通课程、跨学科交叉课程、全球胜任力培养课程和行业领域协同育人课程,学生可根据未来发展意向选择修读相关课程,此部分至少修读6学分。

修读建议如下:

1. 拟继续深造学生建议选择修读本硕贯通专业选修课程。免试推荐攻读本校研究生的本科生可提前学习研究生课程,并计入研究生学分。
2. 拟出国学生建议选择修读全球胜任力培养课程,包括全英文科技前沿课程、国际课程、全球胜任力微专业课程,也可通过境外访学进行国际学分转换。
3. 拟就业学生建议选择行业领域协同育人课程修读,针对未来职业选择修读相应的课程。
4. 学生可根据个人发展需要,选择上述列表中跨学科交叉课程,也可跨专业选修其他专业设置的专业课程。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习、毕业论文等,必修学分10学分。专业实习与毕业论文要符合学校相关规定。专业实习一般在第五学期至第七学期之间进行,要求学生在企业或事业单位从事与专业有关的工作,实习时间至少15天,有实习单位出具证明。学年论文一般在第七学期进行。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文|6|必修|7-8|
|专业实习|3|必修|/|
|学年论文|1(18学时)|必修|/|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少10次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。
