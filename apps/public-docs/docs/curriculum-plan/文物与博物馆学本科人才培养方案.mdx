## 一、培养目标

文物与博物馆学专业培养具有正确的政治方向,强烈的社会责任感,深厚的人文素养,良好的综合素质,宽广的国际视野,扎实的文学、博物馆学理论基础,系统的专业知识,较强的实际运用技能,较好的创新能力,堪当保护和传播中国优秀传统文化重任的复合型人才。能够在博物馆、文物考古研究机构与管理部门、文物与艺术品经营单位、海关、新闻出版、教育等机构从事文物考古与博物馆研究、保护、展陈、教育、管理等工作。

## 二、毕业要求

### (一)素质要求

1. 政治素质:牢固树立正确的国家观、民族观、历史观、文化观和宗教观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感、维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。
2. 综合素养:自觉践行社会主义核心价值观,具有良好思想品德、社会公德和职业道德;热爱劳动,具备良好的心理素质和健康的体魄。
3. 人文素养:具有崇高理想、高尚情操、健全人格,继承和弘扬中华民族优秀传统文化,增强历史自觉,坚定文化自信。
4. 信息素养:了解计算机科学和技术学科的基本理论,掌握现代信息技术运用的基础知识和简单技能,并能够熟练运用于本学科本专业的科研和具体工作中。
5. 专业素养:熟悉我国五千多年的中华文明史,理解中华文明多元一体格局的形成与发展,掌握对出土文物和遗址研究阐释和展示传播的能力,具备提升中华文明影响力和感召力,运用专业知识讲好中国故事的素质。
6. 国际视野:具有全球化视野和国际化思维,能够充分认识中华文明在世界文明发展史上的重要地位和巨大影响力,具备关注国际学科发展的意识,担当传播中华文化的责任。

### (二)知识要求

1. 学科基础与理论:具有深厚的历史学基础,掌握考古学的基本理论和方法,掌握中国不同时段考古体系结构和国外考古学发展概况。
2. 专业核心知识:掌握国内外不同时段不同区域主要考古学文化和各类文物的重要特征,以及文化遗产保护与管理,博物馆藏品管理、公众教育及博物馆运营,文物保护修复等文学、博物馆学基础知识,认识和理解中华民族共同体的形成、发展过程。
3. 研究方法:运用马克思主义唯物史观,将考古方法运用于文学学研究,培养文学、博物馆学的综合研究方法。
4. 学科前沿:了解国内外文博界重要动态,熟悉中国考古学、文学和博物馆学发展趋势,关注学科发展的关键性问题和难题,追踪学科前沿的主要观点和学说。

### (三)能力要求

1. 综合能力:以扎实的专业知识为基础,以文理交叉和跨学科的理念,运用一定的跨文化交流途径,将已经掌握的各种知识和信息进行综合整理和分析组合,掌握文物与博物馆学的本质与规律。
2. 专业能力:具备初步判断不同时段考古学文化以及不同质地和种类文物、各类文化遗产主要特征的能力;能够胜任博物馆保管、教育、管理等工作;能够运用基本技术手段和标准工作方法,实施可移动文物和不可移动文物的保护修复。
3. 应用能力:拥有考古学田野调查、测绘以及考古发掘、报告整理编写,文化遗产保护与管理,博物馆运营管理等能力,熟悉文物保护修复的基本规范和程序。
4. 创新能力:养成探究性和创新性思维习惯,善于运用新理论和新方法,开展科研训练和竞赛活动,改进和提升解决复杂问题的能力,具备“敢闯会创”的创新创业精神。

### (四)实践环节

#### 1. 专业实践

专业实践包括学年论文、毕业实习、毕业论文(设计)等,必修14学分。毕业实习时间要求连续4周,于第4学期结束后的暑假进行,由院系统一安排。劳动教育课程与毕业实习同时进行。毕业实习强调个性化培养、多元化实习方式和方法,注重利用本校民族博物馆等已有资源培养学生从事文博工作的实际动手能力。根据专业特色和行业需求,分为“田野考古调查发掘”、“博物馆运营实践”、“文化遗产调研”三个方向进行,学生在教师的指导下选择参加一个方向完成毕业实习。每个方向实习除时间相同外,分别制定详细的考核标准和评价体系细则,严格规范实习内容、要求和报告写作。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|6|必修|第4学期结束后的暑假|
|学年论文(设计)|2(36学时)|必修|6|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少3次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

校级社会实践可以使用 URTP(中央民族大学本科生创新训练项目)、BEIJ(北京市大学生创新训练项目)、GCCX(国家大学生创新训练项目)的实践成果,但该成果不可同时申报创新教育的学分。

学术讲座报告,第1-7学期每学期至少参加3次本专业组织的讲座,第7学期末提交参加讲座的签到表(主讲人、讲座题目、时间、地点),同时提交一份3000字左右与讲座内容有关的研究综述。由班导师具体负责组织签到和评阅,给出成绩。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分,学校体育运动队队员可免修“大学体育”公共必修学分。
