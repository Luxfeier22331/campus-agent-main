## 一、培养目标

文物与博物馆学专业培养具有正确的政治方向,强烈的社会责任感,深厚的人文素养,良好的综合素质,宽广的国际视野,扎实的文学、博物馆学理论基础,系统的专业知识,较强的
实际运用技能,较好的创新能力,堪当保护和传播中国优秀传统文化重任的复合型人才。能够在博物馆、文物考古研究机构与管理部门、文物与艺术品经营单位、海关、新闻出版、教
育等机构从事文物考古与博物馆研究、保护、展陈、教育、管理等工作。

### (四)实践环节

#### 1. 专业实践

专业实践包括学年论文、毕业实习、毕业论文(设计)等,必修14学分。毕业实习时间要求连续4周,于第4学期结束后的暑假进行,由院系统一安排。劳动教育课程与毕业实习同
时进行。毕业实习强调个性化培养、多元化实习方式和方法,注重利用本校民族博物馆等已有资源培养学生从事文博工作的实际动手能力。根据专业特色和行业需求,分为“田野考古
调查发掘”、“博物馆运营实践”、“文化遗产调研”三个方向进行,学79生在教师的指导下选择参加一个方向完成毕业实习。每个方向实习除时间相同外,分别制定详细的考核标
准和评价体系细则,严格规范实习内容、要求和报告写作。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|6|必修|第4学期结束后的暑假|
|学年论文(设计)|2(36学时)|必修|6|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少3次,积极
参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

校级社会实践可以使用 URTP(中央民族大学本科生创新训练项目)、BEIJ(北京市大学生创新训练项目)、GCCX(国家大学生创新训练项目)的实践成果,但该成果不
可同时申报创新教育的学分。

学术讲座报告,第1-7学期每学期至少参加3次本专业组织的讲座,第7学期末提交参加讲座的签到表(主讲人、讲座题目、时间、地点),同时提交一份3000字左右与讲座内
容有关的研究综述。由班导师具体负责组织签到和评阅,给出成绩。
