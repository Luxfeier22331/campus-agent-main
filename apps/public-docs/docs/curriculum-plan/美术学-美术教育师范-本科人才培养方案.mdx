## 一、培养目标

本专业根据新时代我国师范教育和美术教育高质量发展的要求,适应北京地区基础教育美育发展需求,秉承中央民族大学“美美与共,知行合一”的校训精神,培养德、智、体、美、劳全面发展,具有高尚的职业道德、深厚的教育情怀、健康的心理素质、丰富的美术理论知识、全面的美术教育技法,广博的文化科学知识和较强的艺术创作能力和终身学习能力,勇于创新教学,擅于运用以美育人、以美化人、以美培元等美育教育方式的高素质专业化创新型中小学美术老师,能够成为北京市培养中小学学生发展艺术素养的教学骨干和美术教育教学改革的中坚力量。

学生应在如下方面达到中小学美术教师的标准:

1. 践行师德规范和教育情怀:认同教师工作的意义和专业性,能够在美术教育教学中贯彻党的教育方针,通过美育的方式,增进中小学生对中国特色社会主义的思想认同、政治认同、理论认同和情感认同。能够通过美术教育教学活动做学生锤炼品格、学习知识、创新思维、奉献祖国的引路人。

2. 教学与育人:具备全面的美术专业素养,具有整合人文、社会、科学相关知识的能力,在教育实践中,能够依据所教学科课程标准,针对中学生身心发展和学科认知特点,进行教学设计、实施和评价,能够胜任课内外中学美术教育教学工作及社团管理和班主任工作,能够结合学科教学、学校文化参与组织主题教育和社团活动,对学生进行教育和引导。

3. 终身学习与自我发展:了解国内外基础教育改革发展动态,能够适应时代和教育发展需求,进行学习和职业生涯规划。初步掌握反思方法和技能,具有一定创新意识,运用批判性思维方法,学会分析和解决教育教学问题。理解学习共同体的作用,具有团队协作精神,掌握沟通合作技能,具有小组互助和合作学习体验。具有自主学习、终身学习和专业发展意识,养成主动运用多种手段和方法获取知识的习惯。

## 二、毕业要求

### (一)素质要求

1. 政治素质:具有坚定的思想政治信念、牢固树立正确的祖国观、民族观、历史观、文化观和宗教观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。

2. 教育情怀和师德规范:具有立德树人理念、依法执教意识,具备正确的教师观、学生观,具有情系学生、献身教育的爱心、责任心、事业心,确立“四有好教师”的理想追求,能够自觉践行师德规范,能够立志做学生成长的引路人。

3. 综合素养:掌握基本的现代信息技术,具有一定的国际视野和跨文化交流能力;人文、科学和艺术素养良好,热爱劳动,身心健康。

4. 反思学习:建立反思意识与批判性思维、终身学习与专业持续发展意识,能够适应时代和社会发展需求,进行自我学习和美术教师职业生涯规划。

5. 国际视野:具备全球意识、教育国际视野和创新能力,并应用到我国中小学教育教学实践中。

### (二) 知识要求

1. 基础理论知识:掌握美术学和教育学的基本理论和知识、原理,理解美术学科知识体系的基本思想和探究方式,理解和掌握美术核心素养内涵,掌握基于美术学科核心素养的教育方法和策略。

2. 方法与技能:掌握绘画、设计等美术学基础创作方法,以及美术教育教学策略和方法,掌握应用信息技术优化美术课堂教学的技能,了解中学德育原理与方法,能够熟练的在中小学美术教学与美育工作加以运用。

3. 跨学科知识:具备整合美术专业知识与人文、社会、科学相关知识的能力,了解美术学科与社会实践的联系。

### (三)能力要求

1. 综合育人能力:具有美术学科育人的意识,初步掌握综合育人的路径与方法,能够将德育和心理健康教育融入美术教学实践与校园文化活动中,具有一定的综合育人能力。

2. 教学能力:具备美术教学实践能力与美术教学研究能力,能够根据学生身心发展规律和美术学科认知特点,以学习者为中心,创设学习环境,设计适切的教学策略和方法,进行教学设计实施,开发特色校本美术课程,开展多元综合学习评价,能够运用多种手段和方法对美术教育教学进行反思和研究,能熟练地将现代信息技术融合到自己的教学实践中,具备运用现代教育技术从事美术教学和组织管理的能力。

3. 班级指导:具有良好的表达能力、沟通能力和组织能力,具有社团管理与指导的能力,能够参与德育和心理健康教育等班级教育活动的组织与指导。

4. 沟通合作能力:具有良好的语言表达能力,具有较强的交流合作能力,理解学习共同体的作用,具有团队协作精神,掌握沟通合作的技能与方法。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、教育见习、教育实习、教育研习、毕业实习、毕业论文(设计)等,必修学分17分。

部分专业实践内容和要求简要如下:

教育见习:教育见习主要是通过教学观摩进行“自我教育”,针对不同的课堂教学,根据实际教学内容,对课堂教学的组织形式、教学过程、教学特点、课堂师生间互动、教师角色等方面进行有目的的、系统的观察和反思。

教育实习:在前期教育见习的基础上,练习教学方法和教学技能,进行备课和编写教案;通过辅导学生,批改作业,以熟悉各个教学环节;在教育实习实践中深入领会教学大纲、课程设置和教材之间的关系。

教育研习:教育研习目的在于引导学生了解和体验教学研究活动,实现教学能力和研究能力的同步增长,进而提升自身的教育创新能力。

教育毕业实习:学生在完成本科阶段大部分专业课和教师教育课程的学习后,进入中学进行教育实习。在实习过程中,学生将完成备课、讲课、批改作业等教学过程,学习班级管理,完成学校各类美育任务。

|类别|学分|修读性质|学期|
|---|---|---|---|
|教育见习|2|必修|3-4|
|教育实习|1.5|必修|5|
|教育研习|1.5|必修|6|
|毕业实习|4|必修|7|
|民族地区文化考察与写生汇报展示|1|必修|5|
|学年论文(设计)|1|必修|6|
|毕业论文(设计)|6|必修|7-8|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。
