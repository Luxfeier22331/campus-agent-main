## 一、培养目标

本专业培养政治素质过硬、牢固树立人类命运共同体和中华民族共同体意识,具有宽广的国际视野、深厚的家国情怀、扎实的俄语基本功和专业知识与能力、一定的中亚国家语言知识与能力,熟悉俄罗斯、中亚社会和文化,能够参与和俄罗斯、中亚相关的国际事务,积极为国家“一带一路”建设和民族团结进步事业服务的俄语和中亚语兼通、跨文化交流能力强的复合型俄语人才。

## 二、毕业要求

### (一)素质要求

1. 政治素质:具有坚定正确的政治方向、牢固树立正确的祖国观、民族观、历史观、文化观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,有坚定的中华民族共同体意识,对西方文化具有批判性思维意识。
2. 综合素养:自觉践行社会主义核心价值观,具有正确的世界观、人生观和价值观,良好的思想品德和社会公德;掌握基本的现代信息素养,具有一定的国际视野和较强的逻辑思维能力;人文和科学素养良好,热爱劳动,身心健康。

### (二)知识要求

1. 理论知识:初步掌握语言研究、文学批评、国别与区域研究、跨文化研究的基础理论和基本方法,了解俄语、一门中亚语及相关领域的最新动态和发展趋势。
2. 专业核心知识:系统掌握俄语语音、词汇、语法、语篇、修辞等语言知识,熟悉俄罗斯经典作家及其作品;掌握一门中亚国家语言的语音、词汇、语法等知识;了解俄罗斯及中亚国家的历史、地理、政治、经济、社会、文化等领域知识;熟悉中华文化及中华民族共同体知识。
3. 跨学科知识:具有宽广的人文和社会科学知识,形成跨学科知识结构,能够进行跨学科思考。

### (三)能力要求

1. 专业能力:具有较强的俄语听、说、读、写、译能力和一定的一门中亚国家语言运用能力,具有良好的文学赏析能力,具有一定的研究能力。
2. 跨文化交流能力:能以开放的态度对待多元文化现象,能敏锐觉察、合理诠释文化差异,能灵活运用策略进行有效的跨文化沟通。
3. 思辨能力:具有逻辑思维能力、批判意识和创新精神,能够发现、辨析、质疑、评价本专业及相关领域的现象和问题,形成个人的判断和见解。
4. 创新能力:养成探究性学习和创新性思维习惯,能够发现、质疑、辨析和评价本专业相关问题,具有良好的实际动手和解决复杂问题的能力,具备“敢闯会创”的创新创业精神及终身学习与自我发展的能力。

## 三、学制、总学分和学位授予

学制:4年

总学分:181 学分

学位授予:文学学士

## 四、各教学环节学时学分

将本科修读阶段分为大类培养、专业培养和个性化培养三个阶段。大类培养阶段,主要开展通识教育和学科基础教育,合计70学分,其中必修62学分,选修8学分。专业培养阶段,主要开展专业教育,合计91学分,其中必修56学分,选修35学分(其中至少选修25学分中亚语课程)。个性化培养阶段,主要开展个性化教育,俄语(俄语、中亚语)专业学生至少选择修读6学分,均为选修学分。另外,实践环节合计14学分,为必修。

### (四) 实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、毕业实习、毕业论文(设计)等,必修学分10分。

学年论文在第六学期进行,结合第三学年专业课程学习,在指导教师的指导下确定论文题目、搜集文献、开展研究,用俄语撰写本专业领域论文,不少于1500词。

毕业实习原则上在第三学年的暑假期间进行,时间不少于4周,要求运用所学专业外语进行口笔译、外事服务、外贸导游、与外语相关的新闻采访编辑以及各级各类学校的外语教学等实习活动。实习结束后提交实习单位鉴定表和1000-1500字的中文实习总结。

毕业论文的形式以学术研究论文为主,选题应与俄语(中亚语)语言学、文学、语言文化学、俄罗斯及中亚(区域或国别)社会与文化等领域相关。根据学生未来发展规划,学生可以自主选择用俄语或汉语撰写论文,用俄语或汉语进行答辩。学术论文写作应符合学术规范,如用俄语撰写,篇幅不少于4000词,如用汉语撰写,篇幅不少于10000字。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|6|
|毕业实习|3|必修|大三暑假|
|学年论文(设计)|1|必修|7-8|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|大二暑假|
|学术讲座报告|0.5|必修|1-7|
|第二课堂(志愿服务、文体活动等)|0.5|必修|1-7|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分,学校体育运动队队员可免修“大学体育”公共必修学分。
