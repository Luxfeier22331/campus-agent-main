## 一、培养目标

本专业培养具备坚定的马克思主义理想信念、深厚的古典人文思想与宽广的现代理论视野,掌握实证主义社会调查和统计分析技术,重视田野作业和诠释主义质性研究方法,具备社会调查、社会规划、社会建设、社会治理、社会服务和社会评估等社会学专业能力的复合型创新人才。毕业生可以在教育部门、科研机构、党政机关、传媒机构、企事业单位和社会团体从事社会调查与研究、政策设计与评估、社会规划与预测、传播策划与管理、组织管理与咨询、市场调查与数据分析等工作。

## 二、培养规格/标准

1. 热爱社会主义祖国,拥护中国共产党,具有良好思想品德、社会公德和职业道德,自觉践行社会主义核心价值观,具有家国情怀和中华民族共同体意识。
2. 掌握社会学理论的发展历史和主要流派,并能够理解各派理论的逻辑关系。
3. 掌握社会调查和研究方法,并掌握社会统计原理和数据分析方法。
4. 能够综合运用社会学理论和社会研究方法,进行社会问题分析和公共政策建议。
5. 掌握现代信息技术和外语能力,具备理论思维能力、逻辑分析能力和批判反思能力。熟悉中西方社会发展转型的历史趋势,具备国际视野,适应全球化转变。
6. 具有自主学习能力和终身学习意识,具有良好的心理素质和健康体魄。

## 三、主干学科

社会学

## 四、核心课程

社会学导论、社会研究方法、社会统计学、古典社会理论、现代社会理论、社会心理学、社会分层与流动、民族社会学

## 十、有关说明

1. 本培养方案总学分(专业基础课+专业方向课+实践教学环节)/原2018版培养方案中的学分(学科基础课+专业基础课+专业方向课+其他实践教学环节)(百分比=55/112*100%=49.1%)。
2. 学有余力的学生可根据自身情况,多修学分或提前修学分。
3. 社会实践(社会实践报告):通过参与各类与专业相关的社会实践活动,撰写实践报告,不少于 3000 字。
4. 讲座报告:第 1-4 学期每学期至少参加 3 次本专业组织的讲座,第 4 学期开学第三周提交参加讲座的签到表(主讲人、讲座题目、时间、地点),同时提交一份 3000 字左右与讲座有关的研究综述。
