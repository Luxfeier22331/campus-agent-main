## (2020版)

## 一、培养目标

本专业培养具备具有坚定的马克思主义理想信念、深厚的古典人文思想与宽广的现代理论视野,掌握实证主义社会调查和统计分析技术,重视田野作业和诠释主义质性研究方法,具备
社会调查、社会规划、社会建设、社会治理、社会服务和社会评估等社会学专业能力的复合型创新人才。毕业生可以在教育部门、科研机构、党政机关、传媒机构、企事业单位和社会
团体从事社会调查与研究、政策设计与评估、社会规划与预测、传播策划与管理、组织管理与咨询、市场调查与数据分析等工作。
