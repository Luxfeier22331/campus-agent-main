## 一、培养目标

本专业服务“一带一路”建设、西部和民族地区经济发展,培养践行社会主义核心价值观,具有良好思想品质和道德修养,掌握经济学以及国际经济贸易的专业基础知识、基本理论和
方法,熟悉国际通行的经贸规则,熟练使用1门外语和现代信息技术,具有全球视野,具有良好的沟通、应变、协调能力和创新创业精神,适应我国现代化建设需要的应用型、复合型
、创新型人才。

## 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,必修10学分。

学年论文一般不少于 8000 字,需有完整的文献综述和研究设计,可作为毕业论文的预研究,四年级开学后提交。

毕业论文一般不少于 10000 字,需使用规范的经济学研究方法,要完成开题报告、毕业论文写作与通过论文答辩。

毕业实习时间累计不少于8周,最终提交实习报告和实习证明。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|3|必修|7-8|
|学年论文(设计)|1|必修|6-7|

### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极
参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合
素养课中相应类别课程2学分。
