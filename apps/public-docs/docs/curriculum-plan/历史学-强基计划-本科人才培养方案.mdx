## 一、培养目标

以马克思主义为指导,以铸牢中华民族共同体意识为主线,按照“厚基础、宽口径、强交叉、重贯通”的育人理念,培养具有深厚的理论修养、扎实的史学功底、多元的学科结构、宽
广的国际视野、敏锐的思辨能力和突出的创新意识,掌握历史信息搜集、考证与分析的基本方法,能在历史过程和现实处境中考察特定的历史现象,形成合理见解的历史学研究型拔尖
人才。

## (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

### 1. 专业实践

专业实践包括学年论文、专业实习、毕业论文等,合计17学分,为必修。学年论文和毕业论文原则上应为历史学专业论文,其中学年论文不低于8千字且具有一定的学术创新性,毕
业论文不低于1万字且具有较好的学术创新性。

|类别|学分|修读性质|学期|具体要求|
|---|---|---|---|---|
|学年论文|2|必修|5-6|指导老师评分|
|专业实习|3|必修|4-6|以实习报告为依据|
|毕业论文*|6|必修|7-8|全部参加答辩|
|学术会议|3|必修|1-6|参加校内外学术会议|
|重大课题|3|必修|1-6|参加国家民委基地项目或导师主持的省部级以上项目|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告,积极参加党和
国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生“第二课堂”教育方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修||
|学术讲座报告|0.5|必修|1-8|
|第二课堂(志愿服务、文体活动等)|0.5|必修|1-8|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修6学分(必须在导师指导下完成至少1项大学生创新训练项目)。

|类别|学分|修读性质|学期|具体要求|
|---|---|---|---|---|
|学科竞赛|2|必修|1-6|参加规定的学科竞赛|
|创新教育(科研项目)|4|必修|1-6|完成1项大学生创新创业项目|
