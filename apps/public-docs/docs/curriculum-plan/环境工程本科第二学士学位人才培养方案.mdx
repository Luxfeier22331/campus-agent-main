## 一、培养目标

本专业着眼于国家环境保护事业的人才需求,基于工程人才国际化认证的要求,培养具有扎实的环境工程专业的基本理论、知识和技能,一定的工程设计、项目开发与管理能力,能够从事环境工程方面的新理论、新工艺和新设备研究和开发等基础工作的复合型专业技术人才。

## 二、毕业要求

### (一)素质

1. 政治素养:牢固树立正确的祖国观、民族观、历史观、文化观和宗教观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。

2. 社会公德:自觉践行社会主义核心价值观,具有良好思想品德和社会公德。

3. 科学和专业素养:具备深厚的专业素养和严谨的科学精神,具备批判性思维,拥有良好的时代意识和宽广的国际视野。

4. 综合素养:掌握基本的现代信息技术,具有一定的国际视野和跨文化交流能力,人文、科学和艺术素养良好,热爱劳动,身心健康。

### (二)知识

#### 1. 学科基础和理论

具有深厚的数学、物理、化学等自然科学基础和基本的工程技术理论,掌握环境工程研究的基本方法,能够运用基本的学科理论和方法分析环境工程领域相关问题。

#### 2. 核心知识

掌握环境工程的基本理论和核心知识,能够运用专业理论分析环境工程领域的问题和发展规律。

#### 3. 研究方法

掌握环境工程的基础研究方法、实验技术和工程手段,并能够熟练将其应用于科学研究、教学、管理和工程实践。

#### 4. 学科前沿

了解环境工程领域国内外前沿动态和发展趋势,并能通过现代技术手段获取前沿知识。

#### 5. 跨学科知识

了解相关领域的政策法规、行业动态,学习相关的人文知识和社会科学知识,建立跨学科思维。

### (三) 能力

1. 专业能力:具备运用现代信息技术和外语等解决实际问题的能力,具有基本的科学研究和实际工作能力,具有适应社会发展的意识、知识和能力,初步具备本专业的科研、开发和服务能力。

2. 批判性思维:具备批判性思维和创新能力,能够质疑、发现、分析专业及相关领域的现象和问题。

3. 创新能力:能够综合分析研究环境工程专业领域内的复杂问题,并提出相应对策或解决方案。

4. 沟通写作能力:能够有效开展小组学习、专题讨论、团队协作等,具有团队合作精神。

## 三、学制、总学分和学位授予

学制:2年

总学分:75 学分

学位授予:工学第二学士学位

### (二)专业实践

1. 毕业论文(设计)均可以本专业工程设计完成。毕业设计成果主要包括文献综述、任务的提出、方案论证、设计与计算、技术经济分析、结束语等,并附有相应的设计图纸和计算书,至少一个主要构筑物(设备)的设计图纸达到扩大初步设计程度。

毕业论文训练主要包括文献综述、技术调查、实验方案设计、结果分析、绘图和写作、结题答辩和专业文献翻译等内容。

毕业论文(设计)6学分,实行指导教师负责制,第3-4学期完成,累计不少于18周,其中应包括指导教师安排的不少于累计24小时的工程实践环节,并提交相应的实践总结。

2. 专业实习可以工程见习等形式完成,具体办法另行规定。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|3-4|
|专业实习|3|必修|1-3|

## 六、有关说明

1. 本培养方案依据《普通高等学校本科专业目录(2022年)》、《普通高等学校本科专业类教学质量国家标准》(2018)、学校相关文件以及学院具体情况等制订。其中理论课以18学时/学分计,实验课以36学时/学分计。根据环境工程专业属于应用学科的特点,将实验技能训练作为培养学生实践能力的重要实践环节。

2. 本专业学生应具有必要的数学、物理、化学、生命科学专业基础,未修过高等数学(或微积分、数学分析,≥ 4学分)、概率论与数理统计(≥ 3学分)、线性代数(≥ 3学分)、大学物理(含实验,≥ 4学分)、基础化学类课程(无机化学、分析化学、有机化学,含实验,累计≥ 10学分)、物理化学(含实验,≥ 4学分)、仪器分析(含实验,≥ 4学分)等先修课的,应在环境科学与工程类本科人才培养方案或相近方案中开设的下列课程中相应选修,不计入学分。
