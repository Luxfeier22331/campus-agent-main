## 一、培养目标

坚持以习近平新时代中国特色社会主义思想为指导,依托专业学术传统优势和综合比较研究优势,培养具有坚定正确的政治方向、深厚的家国情怀、宽广的国际视野、较好的综合素养,扎实的中国语言文学学科基本理论与中国少数民族语言文学专业知识,较强的文字研究、文学感悟、文献典籍阅读、审美鉴评和实践创新能力,兼通国家通用语言和民族语言,能够在少数民族语言文学领域从事教学、科研、翻译、新闻出版、广播电视、行政、司法等方面工作的高水平复合型人才和理论创新人才后备力量。

## 二、毕业要求

### (一)素质要求

1. 政治素质:热爱社会主义,拥护中国共产党,牢固树立正确的历史观、民族观、国家观、文化观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感和维护民族团结和祖国统一的使命感,自觉铸牢中华民族共同体意识。

2. 思想品德:自觉践行社会主义核心价值观,具有良好思想品德和社会公德。

3. 综合素养:热爱中华优秀传统文化,掌握基本的信息素养,具有国际化视野和跨文化交流能力,人文、科学和艺术素养良好,热爱劳动,身心健康;具有自主学习和终身学习意识。

4. 语言素养:兼通国家通用语和中国少数民族语言,掌握一门以上外语。

5. 职业素养:具有强烈的社会责任感和健康的人际交往意识,熟悉国家在少数民族语言文字及文学创作、传播和研究方面的方针、政策和法规。

### (二)知识要求

1. 学科基础与理论:具备中国语言文学学科基本理论和基本知识,具有扎实的语言学、文学、文献学理论功底。

2. 专业核心知识:具备中国少数民族语言文学专业的基本理论和基本知识。

3. 研究方法:掌握必备的科学理论与研究方法,了解专业及相关领域最新国内外前沿动态和发展趋势。

4. 跨学科知识:掌握一定的哲学、历史等人文学知识以及信息技术应用基础知识。

### (三)能力要求

1. 专业能力:在国家通用语言和民族语言的阅读理解、口语表达、书面表达等方面体现出明显的优势,具有感悟、辨析和探究语言文学现象的能力,能够综合运用所学知识鉴赏、评价文学作品和相关文化现象。熟练掌握计算机及信息技术应用、数据库应用、文献检索等工具性知识。

2. 创新能力:养成探究性学习和创新性思维习惯,适应社会知识型人才的需求以及社会的发展,具有良好的实际动手和解决复杂问题的能力,具备“敢闯会创”的创新创业精神。

3. 跨文化交流能力:具备适应国际社会发展的意识、知识和能力,具有与周边国家进行畅通的跨文化交流能力,具有基本的国际交流学习能力。

### (三)个性化培养

为充分对接学生未来发展、满足学生个性化选择,设置本硕贯通课程、跨学科交叉课程、全球胜任力培养课程和行业领域协同育人课程,学生可根据未来发展意向选择修读相关课程。

修读建议如下:

1. 个性化培养至少选择修读6学分。

2. 拟继续深造学生建议选择修读本硕贯通专业选修课程。免试推荐攻读本校研究生的本科生可提前学习研究生课程,并计入研究生学分。

3. 拟出国学生建议选择修读全球胜任力培养课程,包括全英文科技前沿课程、国际课程、全球胜任力微专业课程,也可通过境外访学进行国际学分转换。

4. 拟就业学生建议选择行业领域协同育人课程修读,针对未来职业选择修读相应的课程。

5. 本专业人才培养可分为两类, 一是本科毕业即就业的学生, 建议修读跨学科交叉课程和行业领域协同课程为主;二是本科毕业继续深造的学生,建议修读本硕贯通课程和全球胜任力培养课程为主。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,合计10学分,为必修。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|3|必修|/|
|学年论文(设计)|1(18学时)|必修|/|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少10次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。以上活动以签到、报告或证明为准。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,本专业方向必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。
