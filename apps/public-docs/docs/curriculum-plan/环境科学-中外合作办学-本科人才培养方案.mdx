## 一、培养目标

本专业培养德智体美全面发展,具有可持续发展理念和国际化视野,具备生态环境科学的基本理论、基本知识和基本技能,掌握相关专业的国际最新前沿专门知识和技能,能够在生态环境保护相关领域从事教育、研究与开发、咨询和管理等工作的国际化高素质专门人才,能够积极参与环境保护相关领域的国际活动,为促进中国和人类社会的绿色可持续发展做出积极贡献。

## 二、毕业要求

### (一)素质要求

1. 政治素养:牢固树立正确的祖国观、民族观、历史观、文化观和宗教观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。
2. 社会公德:自觉践行社会主义核心价值观,具有良好思想品德和社会公德。
3. 科学和专业素养:具备深厚的专业素养和严谨的科学精神,具备批判性思维,拥有良好的时代意识和宽广的国际视野。
4. 综合素养:掌握基本的现代信息技术,具有较强的跨文化交流能力,人文、科学和艺术素养良好,热爱劳动,身心健康。

### (二)知识要求

#### 1. 学科基础和理论

具有深厚的数学、物理、化学、生物等自然科学基础,掌握生态环境科学研究的基本方法,能够运用基本的学科理论和方法分析生态环境科学领域相关问题。

#### 2. 核心知识

掌握生态环境科学的基本理论和核心知识,能够运用专业理论分析生态环境科学领域的问题和发展规律。

#### 3. 研究方法

掌握生态环境科学的基础研究方法、实验技术和工程手段,并能够熟练将其应用于科学研究、教学、管理和工程实践。

#### 4. 学科前沿

了解生态环境科学领域国内外前沿动态和发展趋势,并能通过现代技术手段获取前沿知识。

#### 5. 跨学科知识

了解相关领域的政策法规、行业动态,学习相关的人文知识和社会科学知识,建立跨学科思维。

### (三)能力要求

1. 专业能力:具备运用现代信息技术和外语等解决实际问题的能力,具有基本的科学研究和实际工作能力,具有适应社会发展的意识、知识和能力,初步具备本专业的科研、开发和服务能力。
2. 批判性思维:具备批判性思维和创新能力,能够质疑、发现、分析所学专业及相关领域的现象和问题。
3. 创新能力:能够综合分析研究环境科学专业领域内的复杂问题,并提出相应对策或解决方案。
4. 沟通写作能力:能够有效开展小组学习、专题讨论、团队协作等,具有团队合作精神。

## 三、学制、总学分和学位授予

学制:4年(第1、2、4学年在中央民族大学,第3学年在爱尔兰国立科克大学)

总学分:150 学分

学位授予:中央民族大学和爱尔兰国立科克大学理学学士学位

### (三) 实践环节

#### 1. 专业实践

专业实践包括学年论文、专业实习和毕业论文(设计)训练,必修10学分。学年论文和毕业论文(设计)的选题、内容和写作均应符合专业规范。专业实习由学院组织实施,包括认知实习和生产实习等。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|专业实习|3|必修|5-7|
|学年论文(设计)|1|必修|5-6|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少6次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|1-7|
|学术讲座报告|0.5|必修|1-7|
|第二课堂(志愿服务、文体活动等)|0.5|必修|1-7|

#### 3. 创新创业实践

包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

1. 本专业学制4年,学生第1、2年和第4年在中央民族大学进行全日制学习,第3年赴爱尔兰科克大学进行全日制学习。因不达出国标准而不能出国学习者,全部在中央民族大学学习。
2. 按照中央民族大学规定,中方学分计算方法为理论课以18学时/学分计,实验课以36学时/学分;按照爱尔兰科克大学的规定,学分计算方法为24课时课程+12课时辅导记为5学分。因此本方案中规定,中方2学分可换算为外方5学分,实验课程以本方案中的学分计算。
3. 在培养方案外开设高阶应用英语课程,依据学生水平进行分层教学,设置不同学时,以达到出国学习、无障碍接受全英文课程标准为目标。学生可依据自身情况选择不同学时课程。
4. 允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分,学校体育运动队队员可免修“大学体育”公共必修学分。
