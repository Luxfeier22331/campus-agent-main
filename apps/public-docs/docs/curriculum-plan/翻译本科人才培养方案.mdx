## 一、培养目标

本专业面向经贸、新闻、教育、旅游、文化传播等领域,培养具有过硬的政治素质、优秀的跨文化交际能力、广博的人文社科知识、扎实的中英文语言功底与翻译专业技能,熟悉中华文化特色,具有家国情怀和国际视野,致力于推动中华文化的对外传播、用英语讲好中国故事,为国家经济与社会发展做出贡献的高素质翻译人才。

## 二、毕业要求

### (一) 素质

1. 政治素质:具有坚定正确的政治方向,牢固树立正确的祖国观、民族观、历史观、文化观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,有坚定的中华民族共同体意识,对西方文化具有批判性思维意识;
2. 思想品德:自觉践行社会主义核心价值观,具有良好的思想品德和社会公德。
3. 综合素养:掌握基本的现代信息素养,人文和科学素养良好,热爱劳动,身心健康。
4. 职业素养:具有扎实的双语能力,掌握翻译专业技能和跨文化交流能力,遵循翻译从业人员的职业道德和行为准则。
5. 国际视野:树立人类命运共同体意识,具有宽广的国际视野,关注世界的现状与变化,追求人类和谐与共同进步。

### (二) 知识

1. 理论知识:具有扎实的英语语言功底,熟悉中国文化及中华民族共同体知识,掌握英语国家社会、语言文学知识,在文学和语言学等领域形成较为完备的基础知识体系和学术素养。
2. 专业核心知识:掌握英汉语言、文学和文化的基础知识,熟悉翻译学科的相关理论、实践技巧和翻译行业及相关领域的最新动态和发展趋势。

3. 跨学科知识:了解一般性的通识教育基础知识以及新闻传播、文化人类学等相关学科基本知识,形成跨学科知识结构,为职业发展打下良好基础。

### (三)能力

1. 专业能力:具备翻译从业所需的英汉双语表达能力,熟练掌握听、说、读、写、译技能,具备口笔译实际应用能力,具有突出的跨文化交流能力、思辨能力,熟悉中华文化特色,能够用英语讲好中国故事。
2. 创新能力:养成探究性学习和创新性思维习惯,能够发现、质疑、辨析和评价本专业相关问题,具有良好的实际动手和解决复杂问题的能力,能够胜任中华文化题材相关的各类翻译实践,具备“敢闯会创”的创新创业精神及终身学习与自我发展的能力。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文(翻译实践)、专业实习和毕业设计,必修10学分。

学年论文的形式为翻译实践,结合第三学年专业课程学习,在指导教师的指导下确定翻译内容,原则上要求首译,译文不少于10,000汉字或6,000英文单词。

专业实习原则要求在大三暑假完成,时间不少于四周,要求运用所学专业外语进行口笔译、外事服务、外贸导游、与外语相关的新闻采访编辑以及各级各类学校的外语教学等实习活动。实习结束后提交实习单位鉴定表和1000-1500字的中文实习总结。

毕业设计的形式为学术论文或翻译实践报告,学术论文类的毕业设计正文长度不少于 5000 英文单词;翻译实践报告类毕业设计应包括不少于 3000 英语单词的翻译实践和不少于 3000 英语单词的译作评论。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业设计|6|必修|7-8|
|专业实习|3|必修|/|
|学年论文(翻译实践)|1(18学时)|必修|/|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。
