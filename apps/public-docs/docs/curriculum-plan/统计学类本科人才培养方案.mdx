## 一、培养目标

本专业类聚焦国家战略与区域经济社会发展对统计学人才的需求,以强数学基础、重专业实践为指导思想,培养具有过硬的政治素质、深厚的家国情怀、宽广的国际视野、良好的综合
素养、坚实的数学学科基础,较强的统计方法、数据处理的研究和应用能力,能够在大数据与人工智能时代的统计与数量分析行业从事专业技术和管理等工作的实用型和通用型人才。

毕业生能在经济、管理、金融、医学、生物、工程、环境等部门从事统计调查、统计信息管理、数量分析等工作,或在涉及大数据分析的企事业单位从事统计分析和咨询等工作,或在
科研、教育部门从事研究和教学工作。毕业生可继续攻读统计学研究生学位,还可选择攻读数学、计算机和经济管理类研究生学位。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习、毕业论文等,必修学分10学分。专业实习与毕业论文要符合学校相关规定。专业实习一般在第五学期至第七学期之间进行,要求学生在企业或事
业单位从事与专业有关的工作,实习时间至少15天,有实习单位出具证明。学年论文一般在第七学期进行。

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少10次,积
极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。
