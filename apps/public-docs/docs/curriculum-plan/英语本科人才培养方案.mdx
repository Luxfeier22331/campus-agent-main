## 一、培养目标

本专业面向教育、外事、文化、科研等英语相关教学、翻译、研究及管理领域,培养具有过硬的政治素质、强烈的爱国精神、宽广的国际视野,扎实的英语语言文学学科理论基础和英
语语言功底、融通的英美文化知识,深厚的人文素养,良好的道德素质,突出的跨文化交流能力、思辨能力、创新能力和可持续发展潜力的高水平英语人才。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、毕业实习、毕业论文(设计)等,必修学分10分。

学年论文在第六学期进行,结合第三学年专业课程学习,在指导教师的指导下确定论文题目、搜集文献、开展研究,根据所在专业的语种要求撰写本专业领域论文,不少于1500字
/词。

毕业实习原则上在第三学年的暑假期间进行,时间不少于4周,要求运用所学专业外语进行口笔译、外事服务、外贸导游、与外语相关的新闻采访编辑以及各级各类学校的外语教学等
实习活动。实习结束后提交实习单位鉴定表和1000-1500字的中文实习总结。

毕业论文的形式以学术研究论文为主,正文不少于5000英文单词,论文写作应符合学术规范。毕业论文选题应与英语语言学、文学、语言文化学、翻译、国别研究等领域相关。论
文用英语撰写,用英语进行答辩。
