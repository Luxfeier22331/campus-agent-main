## 一、培养目标

本专业面向教育、外事、文化、科研等英语相关教学、翻译、研究及管理领域,培养具有过硬的政治素质、强烈的爱国精神、宽广的国际视野,扎实的英语语言文学学科理论基础和英语语言功底、融通的英美文化知识,深厚的人文素养,良好的道德素质,突出的跨文化交流能力、思辨能力、创新能力和可持续发展潜力的高水平英语人才。

## 二、毕业要求

### (一)素质要求

1. 政治素质:具有坚定正确的政治方向、牢固树立正确的祖国观、民族观、历史观、文化观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,有坚定的中华民族共同体意识,对西方文化具有批判性思维意识。

2. 思想品德:自觉践行社会主义核心价值观,具有良好的思想品德和社会公德。

3. 综合素养:具有基本的现代信息素养,人文和科学素养良好,热爱劳动,身心健康。

4. 职业素养:具有良好的文化素养、社会责任感和职业道德,能够在英语语言文学与翻译相关领域的工作实践中遵守职业道德和相关规范。

5. 国际视野:树立人类命运共同体意识,具有宽广的国际视野,关注世界的现状与变化,追求人类和谐与共同进步。

### (二)知识要求

1. 理论知识:掌握英语语言学、文学批评、翻译以及跨文化研究的基础理论和基本方法;了解英语及相关领域的最新动态和发展趋势。

2. 专业核心知识:系统地掌握英语语音、词汇、语法、语篇、修辞等语言知识,熟悉英美文学史、经典作家及其作品;熟悉英汉翻译及英美社会文化的基本知识;熟悉中国文化及中华民族共同体知识。

3. 跨学科知识:了解一般性的通识教育基础知识以及新闻传播、文化人类学等相关学科基本知识,形成跨学科知识结构,为职业发展打下良好基础。

### (三)能力要求

1. 专业能力:具有良好的英语综合应用能力、科研能力以及独立工作的能力,一定的第二外国语实际应用能力,能够综合运用已有知识和经验提出见解、探索方法、解决问题,不断适应新环境和新形势的挑战。

2. 思辨能力:能够提出探索性问题,通过多种渠道获取信息,以科学研究的方法来分析问题、解决问题,善于运用推理和反思在研究中获得结论。

3. 跨文化交流能力:理解和尊重世界文化的差异性和多样性,能够熟练运用跨文化沟通技巧,在跨文化背景下顺利展开沟通。

4. 创新能力:养成探究性学习的习惯和创新性思维能力,能够发现、质疑、辨析和评价本专业相关问题,解决英语语言、文学、翻译和跨文化交流等领域复杂问题的能力,具备“敢闯会创”的创新创业精神及终身学习与自我发展的能力。

## 三、学制、总学分和学位授予

学制:4年

总学分:158 学分

学位授予:文学学士

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、毕业实习、毕业论文(设计)等,必修学分10分。

学年论文在第六学期进行,结合第三学年专业课程学习,在指导教师的指导下确定论文题目、搜集文献、开展研究,根据所在专业的语种要求撰写本专业领域论文,不少于1500字/词。

毕业实习原则上在第三学年的暑假期间进行,时间不少于4周,要求运用所学专业外语进行口笔译、外事服务、外贸导游、与外语相关的新闻采访编辑以及各级各类学校的外语教学等实习活动。实习结束后提交实习单位鉴定表和1000-1500字的中文实习总结。

毕业论文的形式以学术研究论文为主,正文不少于5000英文单词,论文写作应符合学术规范。毕业论文选题应与英语语言学、文学、语言文化学、翻译、国别研究等领域相关。论文用英语撰写,用英语进行答辩。

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分,学校体育运动队队员可免修“大学体育”公共必修学分。
