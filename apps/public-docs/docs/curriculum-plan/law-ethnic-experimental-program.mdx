法学专业1979年开始招生,2001年招收首批硕士研究生,2002年在全国首设本科法学+英语方向,2003年设立民族法学博士学位授予点,2011年获批法学硕士一级学科,2012年入选首批应用型、复合型卓越法律人才培养计划,2014年设立国内首批法学藏语实验班。2019年入选首批国家级一流本科专业建设点。2021年获批教育部首批新文科项目。根据服务面向,针对生源情况,法学院以法学专业为基础,在涉外法治人才和民族双语法治人才培养方面形成了鲜明的特色和优势。学院注重培养学生的实践能力,积极开展诊所教学、案例教学、模拟法庭、虚拟仿真实验教学等。

## 一、培养目标

法学(民族实验班)(以下简称“民族班”)人才培养着眼国家当前紧缺的双语法治人才和民族事务治理法治化人才需求,坚持立德树人、德法兼修的培养思路,秉持扎根基层、服务边疆的培养方向,培养德才兼备,具备过硬的政治素质、深厚的家国情怀、高尚的职业伦理,具有扎实的专业理论基础和熟练的职业技能、合理的知识结构,具备依法执政、科学立法、依法行政、公正司法、高效高质量法律服务能力与创新创业能力,熟悉党和国家的民族政策与民族法理论知识,堪当民族复兴大任、勇于维护国家统一、民族团结和边疆稳定,提升民族事务治理法治化水平的复合型、应用型、创新型法治人才及后备力量。

## 二、毕业要求

### (一)素质

1. 政治素质:牢固树立正确的历史观、民族观、国家观、文化观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。具有良好的法律职业伦理,具有服务于建设社会主义法治国家的责任感和使命感。

2. 思想品德:自觉践行社会主义核心价值观,把国家、社会、公民的价值要求融为一体,提高个人的爱国、敬业、诚信、友善修养,自觉把小我融入大我,不断追求国家的富强、民主、文明、和谐和社会的自由、平等、公正、法治,将社会主义核心价值观内化为精神追求、外化为自觉行动。

3. 综合素养:熟悉各民族历史、语言和文化,掌握铸牢中华民族共同体意识方面的理论、政策和法律;掌握基本的现代信息技术,具有一定的国际视野和跨文化交流能力;人文、科学和艺术素养良好,热爱劳动,身心健康;掌握一门外语,具备基本的听说读写能力。能够熟练运用国家通用语言文字和少数民族语言文字进行交流和文书写作,通过中国少数民族汉语水平考试(MHK)四级。

4. 职业素养:熟识法律程序和法律规定,适应法律实践的需求,具备从事法律工作的理想与信念。具备高尚的职业伦理,具有用法律服务于国家发展、民族团结进步和人民福祉提升的素质素养。具备运用国家通用语言文字和少数民族语言文字处理法律事务的职业素质。

5. 国际视野:树立用法律维护人类命运共同体的意识,具有一定的国际视野和跨文化交流能力,了解国际规则,能够运用法治维护国家利益。

### (二)知识

1. 学科基础与理论:熟练掌握习近平法治思想概论、法学导论、宪法、中国法律史、法理学、民法、刑法、现代汉语等学科基础课,熟练掌握理论框架与知识,具备深厚的基础功底与跨文化学习基础。

2. 专业核心知识:法学班需要掌握行政法、经济法、诉讼法、法律职业伦理、国际法、环境资源法、少数民族语言通论等相关学科知识,掌握核心课程,从而提升专业核心知识储备。

3. 研究方法:掌握必备的研究方法,具有专业的法学思维,具备跨文化思考法律问题的能力,具备民族事务治理法治化的思维,具有优秀的问题意识和扎实的研究态度,能够熟练运用法律解释、法律论证、证据证明等方法解决实务问题,开展研究工作。

4. 学科前沿:了解法学专业及相关领域国内外前沿动态和发展趋势,了解相关主题,能够对研究现状、热点与前沿进行系统梳理,进行创新研究。

### (三)能力

1. 专业能力:具备使用双语处理法律实务的能力,具备使用法律与民族政策提升民族事务治理法治化水平的能力,具备独立自主地获取和更新本专业相关知识的学习能力,具备系统的法学思维能力,具备法律文书处理能力。

2. 实践能力:具备将所学的专业理论与知识融会贯通,灵活地综合应用于专业实务之中的基本技能。重点掌握多元纠纷解决能力、基层法律治理能力、案件分析归纳能力、法律文书撰写能力与法制宣传动员能力等。

3. 创新能力:紧密结合当前社会的最新需求,运用跨学科知识,开展科研训练和竞赛活动,养成探究性学习和创新性思维习惯,具备突破式创新、渐进式创新、再运用式创新的能力。

为充分对接学生未来发展、满足学生个性化选择,设置本硕贯通课程、跨学科交叉课程、全球胜任力培养课程和行业领域协同育人课程,学生可根据未来发展意向选择修读相关课程,此部分至少修读2学分。修读建议如下:

拟继续深造学生建议选择修读本硕贯通专业选修课程。免试推荐攻读本校研究生的本科生可提前学习研究生课程,并计入研究生学分。

拟出国学生建议选择修读全球胜任力培养课程,包括全英文科技前沿课程、国际课程、全球胜任力微专业课程,也可通过境外访学进行国际学分转换。

拟就业学生建议选择行业领域协同育人课程修读,针对未来职业选择修读相应的课程。

各专业对于跨学科交叉课程可提出修读建议,学生可根据个人发展需要,跨专业选修其他专业设置的专业课程。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,必修17学分。毕业实习与就业能力考查要求学生到与法律相关的实务部门实习,至少连续2个月以上。西部地区法律实践需要开展与法学相关的实践内容,结合学院规划进行。法律实务训练为专业实践的必修环节,包括民事法律诊所、刑事法律诊所、行政法律诊所、诉讼翻译与审判实务、模拟法庭等,学生只能选择参加其中的一种,经考核合格获得3学分。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习与就业能力考查|5|必修|7|
|西部地区法律实践|2|必修|/|
|学年论文(设计)|1(18学时)|必修|6|
|法律实务训练|3|必修|4-6|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生“第二课堂”教育方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|志愿服务、文体活动等|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。
