## 一、培养目标

经济学拔尖人才创新班培养具备过硬的政治素质、深厚的家国情怀、开阔的国际视野、较强的创新意识,扎实的经济学理论基础,掌握现代经济学分析研究方法,能够运用数理统计工
具,拥有向相关领域拓展、结合其他学科进行深入理论研究和探索、解决实际经济运行问题的能力和较高的外语水平,能够进入国内外高层次机构继续深造或从事研究工作的卓越创新
人才。

## (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

### 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,必修10学分。

学年论文一般不少于 8000 字,需有完整的文献综述和研究设计,可作为毕业论文的预研究,四年级开学后提交。

毕业论文一般不少于10000字,需使用规范的经济学研究方法,要完成开题报告、毕业论文写作与通过论文答辩。

毕业实习时间累计不少于8周,最终提交实习报告和实习证明。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|3|必修|/|
|学年论文(设计)|1(18学时)|必修|/|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极
参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合
素养课中相应类别课程2学分。
