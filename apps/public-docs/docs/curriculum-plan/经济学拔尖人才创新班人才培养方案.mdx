## 一、培养目标

经济学拔尖人才创新班培养具备过硬的政治素质、深厚的家国情怀、开阔的国际视野、较强的创新意识,扎实的经济学理论基础,掌握现代经济学分析研究方法,能够运用数理统计工具,拥有向相关领域拓展、结合其他学科进行深入理论研究和探索、解决实际经济运行问题的能力和较高的外语水平,能够进入国内外高层次机构继续深造或从事研究工作的卓越创新人才。

## 二、毕业要求

### (一)素质要求

1. 政治素质:热爱社会主义祖国,拥护中国共产党的领导,具有良好思想品德、社会公德和职业道德,能自觉践行社会主义核心价值观,具有家国情怀和中华民族共同体意识。
2. 人文素质:具有深厚的人文素养,对历史、社会、艺术以及自然科学具有较深理解,并具备良好的写作能力和语言表达能力,对国内外文明有较深刻的认识。
3. 专业素质:掌握坚实的专业基础知识,掌握习近平新时代中国特色社会主义经济思想,熟练运用马克思主义政治经济学以及西方经济学分析方法,系统把握中国经济运行实践和规律,熟悉中国经济发展的历程及趋势,掌握先进的数理经济知识,能熟练运用现代数理统计工具,并能将经济理论付诸于经济运营实践。
4. 综合素质:能够将国家发展、集体成绩和个人进步有效地结合起来,德智体美劳各方面均衡发展,具有良好习惯、坚定信念和积极向上的精神风貌。

### (二)知识要求

1. 通识性知识:掌握文学、历史、哲学、艺术、管理、法律、社会、写作等方面的知识,对中国和国际文明具有一定的了解,通晓国内外经济社会发展的基本规律。

2. 学科基础知识:掌握马克思主义政治经济学、辩证法、西方经济学、中国的经济政策和法规,掌握经济学学科发展的国内外最新动态和发展趋势。
3. 专业核心知识:系统掌握中国经济前沿以及世界经济发展的趋势,掌握市场理论、金融理论、社会经济实践调查方法、数理经济理论、现代计量统计工具,并具有熟练的国际文献阅读能力以及专业论文写作知识。

### (三)能力要求

1. 理论运用能力:具备运用现代经济分析方法进行社会经济调查和经济分析的能力,具有良好的专业外语应用能力和熟练的计算机操作能力,能够对本专业复杂问题进行综合分析、研究,并将经济理论运用到现实经济运营。
2. 卓越的沟通与组织能力:具有较强的语言表达能力和丰富的人文知识,能够有效地组织并推动集体不断积极向前发展,能够进行有效的沟通,解决集体出现的问题,具备不断超越、推动集体和个人不断取得进步的毅力和能力。
3. 较强的创新能力:具有较强的创新意识,具备良好的思辨能力和自主学习能力,能够发现、分析、质疑、评价经济运行过程中存在的问题,提出创新性解释或创新性解决方案。

### (三)个性化培养

建议拟就业的学生选择行业领域协同育人课程修读,针对未来职业选择相应的课程。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,必修10学分。

学年论文一般不少于 8000 字,需有完整的文献综述和研究设计,可作为毕业论文的预研究,四年级开学后提交。

毕业论文一般不少于10000字,需使用规范的经济学研究方法,要完成开题报告、毕业论文写作与通过论文答辩。

毕业实习时间累计不少于8周,最终提交实习报告和实习证明。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|3|必修|/|
|学年论文(设计)|1(18学时)|必修|/|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分,学校体育运动队队员可免修“大学体育”公共必修学分。
