## 一、培养目标

### (一)专业类培养目标

以习近平新时代中国特色社会主义思想为指导,坚持立德树人根本任务,以铸牢中华民族共同体意识为主线,努力培养政治素质过硬、专业能力突出、人文与科学素养深厚,能够适应新时代我国社会建设和社会治理现代化需要的高层次人才。毕业生能够掌握社会学类专业的基本理论和研究方法,熟悉国情民情社情,尤其是民族地区社会文化与经济发展状况,具有宽广国际视野与深厚家国情怀,具备较强的学术研究及问题分析能力,具有较高的服务社会和管理社会的能力。

社会学类专业按大类招生大类培养,毕业时可选择社会学和社会工作两个不同专业。

### (二)各专业具体培养目标

#### 1. 社会学

培养具备马克思主义世界观和价值观,具有创新意识和国际视野,富有高度社会责任感,系统掌握社会学基础理论和社会研究调查方法,熟悉社会学各分支学科相关知识和民族地区社会文化与经济发展状况,具有社会政策水平和基层社会治理能力的专门人才。毕业生可以在教育部门、科研机构、党政机关、传媒机构、企事业单位和社会团体等从事社会调查与研究、政策设计与评估、社会规划与预测、传播策划与管理、组织管理与咨询、市场调查与数据分析等工作。

#### 2. 社会工作

培养具备马克思主义世界观和价值观,富有高度社会责任感,系统掌握社会工作理论和实务方法,具备社会工作职业伦理,具有社会服务能力的高素质专门人才。学生毕业后可在相关领域从事科学研究,在党政部门、事业单位、社会团体、企业组织、社会组织、慈善组织、国际组织等从事管理与服务方面的专业性工作。

## 二、毕业要求

### (一)素质要求

1. 政治素质。牢固树立正确的祖国观、民族观、历史观、文化观和宗教观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。
2. 公民素养。自觉践行社会主义核心价值观,具有良好思想品质、道德情操和法律意识,秉持温和理性、尊重包容的价值理念,言行举止雅正,具有社会奉献精神和责任担当意识。
3. 综合素养。人文、科学和艺术素养良好,具有自主学习能力和终身学习意识,具有良好的沟通互动、组织协调和团队合作能力,能够践行公平正义理念,热爱劳动,具有健康体魄和良好心理素质。
4. 信息素养。掌握现代信息技术的基本知识和基本技能,能够灵活、高效地获取、评估和利用信息,具备运用信息技术进行学习、交流、合作与解决问题的能力。
5. 专业素养。熟练掌握社会学类专业的基础知识、基础理论和基本方法,积极关心社会、认识社会,能够联系中国社会实际分析和解决社会问题,具备跨文化沟通和自我调适的能力,以及服务社会和管理社会的能力。
6. 国际视野。广泛涉猎世界历史及各国文化,熟悉国际时事热点及科技发展潮流趋势,对世界文化的多样性保持尊重和包容态度,能够运用外语进行研究和交流,积极加强与国外青年的沟通互动,具有国际视野和跨文化交流能力。

### (二)知识要求

1. 基础理论。系统掌握古典与现代社会理论、社会福利思想及社会工作相关理论,能够理解各流派理论的发展历史与逻辑关系,及时跟踪把握当代社会理论的新进展,形成深厚的学科理论基础、宽广的理论视野、良好的理论反思及批判意识,能够做到理论联系实际。
2. 核心知识。具备扎实的社会学类专业知识,能够综合运用社会学理论和社会研究方法,认识、分析和解决社会问题,具备社会调查、社会规划、社会建设、社会治理、社会服务和社会评估等专业能力,具有利用专业所学服务社会、奉献社会的价值取向及知识基础。

3. 研究方法。掌握实证主义社会调查和统计分析技术,重视田野作业和诠释主义质性研究方法,系统掌握并熟练运用社会工作的通用干预策略,帮助工作对象解决困境问题。能够综合运用社会学研究方法及社会工作方法,进行社会问题分析、公共事务建议和社会政策干预。
4. 学科前沿。具备知识更新与探究性学习意识,及时跟踪了解专业领域国内外前沿动态和发展趋势,其中既包括当代社会理论新动态,也包括研究方法上的新进展及分析技术上的新应用。

### (三)能力要求

1. 专业能力。在系统掌握本专业理论知识和研究方法的基础上,能够运用专业视角,发现问题、分析问题和解决问题,具备从事社会调查与研究、市场研究与咨询、社会咨询与规划、政策研究与评估、行政管理与人力资源开发、社会管理与社会服务等方面的职业能力,以及运用专业知识开展创新创业活动、提供社会服务的能力。
2. 实践能力。能够对现实社会有更好的了解、认知和适应,理论联系实际,积极参与社会问题调查研究及创新实践活动,能够对复杂社会问题进行综合分析与研究,并提出相应对策或解决方案。具有良好的沟通、组织、协调、管理和团队合作能力。
3. 创新能力。养成探究性学习和创新性思维习惯,开展科研训练和竞赛活动,具有良好的实际动手和解决复杂问题的能力,具备“敢闯会创”的创新创业精神。
4. 社会服务能力。具有社会责任感,关心社会、认识社会和服务社会,积极开展社会调查研究与实践活动,开展社会服务活动,具有促进社会政策完善及社会进步的价值取向、专业知识和能力。

社会学专业具体毕业要求:学习马克思主义基本原理,掌握社会学理论的发展历史和主要流派,熟悉社会调查研究方法和数据分析方法,能够综合运用所学知识进行社会问题分析,开展社会实践,提供公共政策建议,积极服务社会、奉献社会;具有较强的逻辑分析能力、批判反思能力和自主学习能力,具备国际视野和创新意识,适应全球化潮流。

社会工作专业具体毕业要求:学习马克思主义基本原理,掌握社会工作专业价值伦理、理论知识与实务方法,具有社会责任感和社会服务精神,能够运用专业知识分析问题和解决问题;掌握现代信息技术和外语能力,具有国际视野,熟悉中西方社会工作专业面临的挑战,适应全球化趋势;具有良好的社会沟通能力、社会适应能力和团队合作精神。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文(设计)、专业实习或毕业实习、毕业论文(设计)等,必修13学分。专业实习时间要求连续3-4周,于第4学期结束后的暑假进行,由院系统一安排。劳动教育课程与专业实习同时进行。毕业实习必须有计划、有方案(或项目),有导师或督导指导,是在机构、社会组织、社区、政府机关等进行的实习。毕业论文及学年论文应聚焦社会生活、社会实践、社会发展、社会历史中的实际现象和问题,具有特定的理论价值或实践意义,体现出社会学类专业的理论视角或理论基础。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|6|必修|4|
|学年论文(设计)|1|必修|5|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少7次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

校级社会实践可以使用 URTP(中央民族大学本科生创新训练项目)、BEIJ(北京市大学生创新训练项目)、GCCX(国家大学生创新训练项目)的实践成果,但该成果不可同时申报创新创业实践的学分。第1-7学期每学期至少参加1次本学科组织的讲座,第7学期末提交参加讲座的签到表(主讲人、讲座题目、时间、地点),同时提交一份3000字左右与讲座有关的研究综述。每个学生参加志愿者服务不低于50小时,完成第二课堂体育实践活动,积极参加各类文化活动。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|5-7|
|学术讲座报告|0.5|必修|1-7|
|第二课堂(志愿服务、文体活动等)|0.5|必修|1-7|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分,学校体育运动队队员可免修“大学体育”公共必修学分。
