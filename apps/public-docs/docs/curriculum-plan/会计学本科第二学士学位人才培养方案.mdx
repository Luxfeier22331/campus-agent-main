## 一、培养目标

培养适应社会主义市场经济需要,具备人文情怀、科学素养和创新创业精神,掌握会计、管理、经济、法律和计算机基础知识,具有实践能力和沟通技巧,能够在工商企业、金融企业、中介机构、政府机构、事业单位及相关部门胜任会计、审计及财务管理工作的应用型、复合型、外向型和创新型专门人才。

## 三、学制、总学分和学位授予

学制:2年

总学分:44 学分

学位授予:会计学第二学士学位

## 四、各教学环节学时学分

本科第二学士学位修读阶段分为专业教育和实践环节两个阶段。专业教育阶段开设专业必修课和专业选修课,必修27学分,选修9学分。实践环节主要开展专业实践,合计8学分,为必修。

### (二)专业实践

专业实践包括学年论文和毕业论文,必修8学分。学生撰写论文须合理设计研究方案,对所研究的课题进行比较全面、深入的分析和阐述,并提出一定的独立见解,做到论点明确、论据充分、逻辑清楚、文字通顺。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文|6|必修|4|
|学年论文|2|必修|2|
