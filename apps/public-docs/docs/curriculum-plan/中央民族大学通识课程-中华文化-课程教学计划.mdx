## 一、课程教学目标

紧扣铸牢中华民族共同体意识这一主线,坚持正确的中华民族历史观,围绕中华文化发展进程是中国各民族文化互动交融的过程、核心思想是中国各族人民共同的智慧结晶、当代意义是中国各民族团结繁荣、互渗互鉴的共有精神动力三大主题,系统阐释中华文化的内涵特点、思想基础、发展历程、多元构成、当代转化和世界价值,引导学生准确认识中华文明起源和历史脉络、中华民族的多元一体、中华文化的普遍本质和多元表现,增强师生对中华民族和中华文化的认同感和自豪感,牢固树立休戚与共、荣辱与共、生死与共、命运与共的共同体理念,不断增强各民族学生对中华文化高度认同。

## 二、课程设计

### (一)课程内容

汇聚哲学与宗教学学院、历史文化学院、文学院、中国少数民族语言文学学院的知名专家学者,设计了中华文化内涵特点、思想基础、发展历程、多元构成、当代转化、世界价值六大教育内容版块,包含名师名家主讲、深度对话等形式多样的18讲专题讲座。

### (二)课程教学方式

采取线下和线上、名师名家讲授与学生自学、课堂学习与实践沉浸相结合的方式。

教师教学团队由多个学院的优秀教师组成,将采用名师名家主讲、专家漫谈、师生对话、虚拟仿真、实地参观教学等多样化教学方式,有效增强课程的趣味性、吸引力,充分激发学生学习探究中华文化的热情。

学生在完成课堂学时基础上可根据个人兴趣自主选择线上资源进行拓展学习,线下教学资源将不断进行更新和积累,充分满足学生兴趣学习的需要。

## 三、修读要求

为全校性公共必修课程, 2学分, 36学时。面向新生、在第2学期开设。

## 四、考核方式

课程考核成绩为通过/不通过,不计入平均绩点。完成线上和线下所有专题讲座学习时长的90\%即为通过。
