## 一、培养目标

本专业面向外交外事、国际经贸、对日文化交流、对日宣传、日语教育、科研等行业和领域服务需求,培养政治素质过硬、牢固树立人类命运共同体和中华民族共同体意识,具有宽广
的国际视野、深厚的外国语言文学学科基础、扎实的日语语言基本功和专业能力、宽厚的人文素养、良好的道德素质、突出的跨文化交流能力、思辨能力、创新能力和可持续发展潜力
的高水平日语复合型人才。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,必修学分10分。

学年论文在第六学期进行,结合第三学年专业课程学习,在指导教师的指导下确定论文题目、搜集文献、开展研究,要求撰写本专业领域论文不少于2000字。

毕业实习原则上在第三学年的暑假期间进行,时间不少于4周,要求运用日语进行口笔译、外事服务、外贸导游、与日语相关的新闻采访编辑以及各级各类学校的日语教学等实习活动
。实习结束后提交实习单位鉴定表和1000-1500字的中文实习总结。

毕业论文可采用学术论文、翻译作品与翻译实践报告、调研报告等多种形式。选题应与日语语言学、文学、文化、翻译、国别研究等领域相关。论文可以自主选择用日语或汉语撰写,
用日语或汉语进行答辩。学术论文写作应符合学术规范,使用中文撰写时,字数不少于8000字,同时须有不少于2000字的日文摘要;使用日文撰写时,字数不少于10000
字,同221时须有不少于 1000 字的中文摘要。

|毕业实习|3|必修|大三暑假|
|学年论文(设计)|1|必修|6|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极
参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。
