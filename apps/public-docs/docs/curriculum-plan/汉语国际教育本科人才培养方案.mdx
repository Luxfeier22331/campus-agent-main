## 一、培养目标

为服务“构建人类命运共同体”与“中国文化走出去”战略,本专业培养肩负时代使命,富有创新精神和创业能力,具有多元文化意识和深厚家国情怀、扎实的汉语言文字功底、较高
的外语水平、良好的人文素养、开阔的国际视野和较强的跨文化交际能力,能够胜任汉语国际教育、中外人文交流、中国语言文学和教育学领域等相关工作的复合型国际化人才。

本专业实行“知行研+国际化”特色人才培养模式。“知”是培养学生掌握专业基础知识并形成基本技能。“行”是培养学生将所掌握的基础知识和基本技能运用于教学和实践活动的
能力。“研”是培养学生发现问题、思考问题的研究意识和解决问题的研究能力。“国际化”是培养学生的国际化视野、中华文化的国际传播能力和跨文化的沟通交流能力。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

645

## 1. 专业实践

专业实践包括学年论文、毕业实习、毕业论文(设计)等,必修学分10学分。学年论文四年级开学后提交;毕业论文需完成开题报告、毕业论文并通过论文答辩;毕业实习于三年级
暑假开始,时长需满3个月,最终提交实习报告和实习证明。

|类别|学分|修读性质|学期|
|---|---|---|---|
|学年论文(设计)|1(18学时)|必修|6|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|3|必修|7-8|

### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少6次,积极
参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|1-7|
|学术讲座报告|0.5|必修|1-7|
|第二课堂(志愿服务、文体活动等)|0.5|必修|1-7|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合
素养课中相应类别课程2学分。
