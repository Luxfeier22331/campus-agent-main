中央民族大学预科教育始于1951年,1953年1月正式成立预科部,2008年更名为预科教育学院。预科教育学院是中央民族大学成立最早、培养学生最多、最具民族教育特
色的教学单位。经过70年的发展,预科教育积累了丰富的办学经验,形成了鲜明的办学特色,为国家培养了20000多名各民族人才,为少数民族地区经济社会发展和国家民族团
结进步事业做出了较大贡献,享有很高的社会声誉。

## 一、培养目标

以习近平新时代中国特色社会主义思想为指导,以铸牢中华民族共同体意识为主线,以“办国内一流的少数民族预科教育学院”为目标,持续推进“本预科贯通”的人才培养模式改革
,培养少数民族预科生成为具有远大理想信念、良好思想品德、扎实文化知识基础、较强自我发展能力、优异综合素质,具有强烈社会责任感、深厚家国情怀、宽广国际视野,堪当民
族复兴大任、勇于维护国家统一和民族团结的各民族优秀人才。

## 四、学制

学制一年,实行学年学分制。铸牢中华民族共同体意识教育专题、信息素养、大学英语、心理健康等课程与本科有效衔接,考试合格者,成绩及学分带入本科。
