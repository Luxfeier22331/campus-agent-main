## 一、培养目标

立足北京,面向全国,着眼国际,秉承“立德启智、知行合一、文化融合、国际视野”的育人理念,主要培养政治素质过硬、人文底蕴深厚、国际视野宽广、教育学理论基础扎实、实践能力突出、创新理念先进、道德品质高尚、具有强烈家国情怀、热爱教育事业的教育学研究和应用的复合型人才。学生未来可以胜任教育教学、教育管理、教育研究、教育与心理咨询、教育创业等工作。

目标1:培育优良师德师风意识。提高政治素养,拥护中国共产党的领导和中国特色社会主义制度,铸牢中华民族共同体意识;拥护党和国家的教育方针、政策、理念,遵守教育法律法规,具有良好的道德品质,树立正确的世界观、人生观和价值观,遵纪守法,自觉遵循为人师表、以身立教的职业操守,具有强烈的教育责任感和使命感,热爱教育事业。

目标2:掌握教育专业基础知识。掌握教育学专业和相关领域的基础知识、基本理论和基本技能;熟悉教育发展的基本原理与规律;具备多学科知识基础和深厚的文化修养;具备较强的本专业外文听说读写能力。

目标3:增强教育教学实践能力。能够开展中小学学科教学;熟练掌握信息化教学技能,根据学科内容,使用现代教育技术手段进行教学设计并实施教学活动;能够根据实际情况开展教育管理工作;并能够针对学生学习过程中出现的问题提供教育咨询;能够胜任教育企事业单位的教学产品开发、教学环境设计等工作。

目标4:提高教育科学研究水平。热爱教育科学研究工作,熟练掌握教育科学主要研究方法,能够进行文献信息检索和数据处理,具有独立发现问题、提出问题、分析问题和解决问题的基本能力;了解国内外教育发展动态与趋势,能较为熟练地开展专业领域内的学术交流,具有对跨文化教育和国际教育的基本理解和认识能力。

目标 5: 筑基个人综合品行素养。能够深入了解创新创业相关知识,热爱劳动, 具备强健的体魄和健康的心理, 形成良好的审美素养、高尚的艺术情趣、健全的人格和优秀的品质,具有较强的创新创业精神和教育创业实践能力。

## 三、学制、总学分和学位授予

学制:2年

总学分:60 学分

学位授予:教育学第二学士学位

## 四、各教学环节、学时和学分
