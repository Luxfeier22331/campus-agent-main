## 一、培养目标

本专业类聚焦国家战略与民族地区经济社会发展对数学、信息和计算科学人才的需求,以“强基础、宽口径、重实际、创特色”为指导思想,以数学为基础,以数据信息处理与计算机
应用为发展方向,培养具有过硬的政治素质、深厚的家国情怀、宽广的国际视野、良好的综合素养、扎实的数学基础,掌握信息科学和数据处理的基本理论,拥有较强的数据分析、数
学建模和计算机应用等实际应用能力,能够解决信息技术、数据分析、计算机网络等具体行业应用问题能力的专门人才。毕业生能在信息产业、经济金融、教育、行政管理等部门从事
教学、应用开发和管理工作。

### (四) 实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习、毕业论文等,必修学分10学分。专业实习与毕业论文要符合学校相关规定。专业实习一般在第五学期至第七学期之间进行,要求学生在企业或事
业单位从事与专业有关的工作,实习时间至少15天,有实习单位出具证明。学年论文一般在第七学期进行。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文|6|必修|7-8|
|专业实习|3|必修|/|
|学年论文|1(18学时)|必修|/|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体454活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少10
次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合
素养课中相应类别课程2学分。
