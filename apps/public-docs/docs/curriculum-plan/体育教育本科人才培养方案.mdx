## 一、培养目标

适应国家关于体育教育改革发展需求,坚持立德树人,致力于培养具有过硬政治素质、深厚家国情怀、强烈社会责任感和教育使命感,一定的人文、科学和艺术素养,扎实的体育理论知识、专项运动技能和综合运动技术,娴熟的体育教学训练技能,较强的育人能力和创新与实践能力,能够在中学及体育教育机构、体育运动训练机构等胜任体育教学与锻炼、课余训练与竞赛、体育管理与科学研究等工作的创新性体育人才。

学生毕业后5年左右达到如下发展预期:

1. 信念坚定,师德高尚。理想信念坚定,对伟大祖国、中华民族、中华文化、中国共产党、中国特色社会主义高度认同,自觉践行社会主义核心价值观和弘扬体育精神;具有先进的教育理念和全面的综合素养;热爱体育教师职业,关爱学生,为人师表,自觉贯彻党的教育方针和政策,遵守国家教育法律法规。
2. 精于教学,能力突出。学科素养扎实,掌握学校体育学科知识的基本理论和方法;具有较强的中学“体育与健康”课程教学能力和课程开发能力,能够在掌握多种运动技能的基础上,灵活运用教育学、体育学、心理学等学科的知识和现代信息技术,高质高效地开展体育教学活动,开发体育特色课程。能够针对学生的身心发展特点,设计、组织和指导面向学生群体的课外体育活动。
3. 德育为先,综合育人。具有立德树人的责任意识,能够做到“以体育人”,发挥体育在形成学生良好思想道德品质中的独特作用。
4. 持续反思,终身发展。具有批判反思、终身学习、改革创新的意识和能力,了解国内外体育教育改革的趋势和前沿动态,能够独立开展体育科学、教学研究,发现、分析和解决体育科学和教育教学中的问题。
5. 懂得沟通,善于合作。具有良好的团队协作精神和较强的沟通协调能力,胜任中学体育教学团队的组织、协调和管理工作。

## 二、毕业要求

### (一)素质要求

1. 师德规范:践行社会主义核心价值观,增进对中国特色社会主义的思想认同、政治认同、理论认同和情感认同。贯彻党的教育方针,以立德树人为己任。遵守教师职业道德规范,具有依法执教意识,立志成为有理想信念、有道德情操、有扎实学识、有仁爱之心的好老师。
2. 教育情怀:具有从教意愿,认同教师工作的意义和专业性,具有积极的情感、端正的态度、正确的价值观。具有人文底蕴和科学精神,尊重学生人格,富有爱心、责任心,工作细心、耐心,做学生锤炼品格、学习知识、创新思维、奉献祖国的引路人。
3. 学会反思:具有终身学习与专业发展意识,能够适应时代和教育发展需求,进行学习和职业生涯规划。初步掌握反思方法和技能,具有一定创新意识,运用批判性思维方法,学会分析和解决教育教学问题。

### (二)知识要求

1. 学科基础理论与方法:掌握体育学科的基本知识、基本原理和基本技能,理解体育学科知识体系基本思想和方法。
2. 方法与技能:能够依据所教学科课程标准,针对中学生身心发展和学科认知特点,运用学科教学知识和信息技术,进行教学设计、实施和评价,获得教学体验,具备体育教学基本技能。
3. 跨学科知识:了解国内外体育基础教育改革发展动态,了解体育学科与其他学科的联系,了解体育学科与社会实践的联系,掌握学习科学相关知识的内容和方法,具有一定的科学理念和素养。

### (三)能力要求

1. 育人能力:树立德育为先理念,了解以体育人的基本内涵;了解中学生身心发展和养成教育规律,理解体育学科育人价值,能够有机结合学科教学进行育人活动;了解学校文化和教育活动的育人内涵和方法,参与组织主题教育和社团活动,对学生进行教育和引导。
2. 专业能力:在教育实践中,能够依据所教学科课程标准,针对中学生身心发展和学科认知特点,运用学科教学知识和信息技术,进行教学设计、实施和评价,获得教学体验,具备体育教学基本技能,具有初步的教学能力和一定的教学研究能力。

3. 班级指导:掌握班级组织与建设的工作规律和基本方法,能够参与德育和心理健康教育等教育活动的组织与指导,获得积极体验。
4. 沟通合作:理解学习共同体的作用,具有团队协作精神,掌握沟通合作技能,具有小组互助和合作学习体验。

### (三)个性化培养

为充分对接学生未来发展、满足学生个性化选择,设置本硕贯通课程、跨学科交叉课程、全球胜任力培养课程和行业领域协同育人课程,学生可根据未来发展意向选择修读相关课程,此部分至少修读6学分。修读建议如下:

拟继续深造学生建议选择修读本硕贯通专业选修课程。免试推荐攻读本校研究生的本科生可提前学习研究生课程,并计入研究生学分。

拟出国学生建议选择修读全球胜任力培养课程,包括国际课程、全球胜任力微专业课程,也可通过境外访学进行国际学分转换。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,必修14学分。

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分。
