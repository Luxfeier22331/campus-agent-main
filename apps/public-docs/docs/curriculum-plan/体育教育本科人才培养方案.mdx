## 一、培养目标

适应国家关于体育教育改革发展需求,坚持立德树人,致力于培养具有过硬政治素质、深厚家国情怀、强烈社会责任感和教育使命感,一定的人文、科学和艺术素养,扎实的体育理论
知识、专项运动技能和综合运动技术,娴熟的体育教学训练技能,较强的育人能力和创新与实践能力,能够在中学及体育教育机构、体育运动训练机构等胜任体育教学与锻炼、课余训
练与竞赛、体育管理与科学研究等工作的创新性体育人才。
