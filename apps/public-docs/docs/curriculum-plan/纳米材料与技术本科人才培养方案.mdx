## 一、培养目标

本专业聚焦国家战略和区域经济社会发展对纳米材料与技术人才的需求,以厚基础、宽口径、强交叉、重贯通为指导思想,培养德、智、体、美、劳全面发展,具有过硬的政治素质、深厚的家国情怀、宽广的国际视野、扎实的数理化与材料科学基础、系统的纳米技术专业知识、熟练的纳米器件制备和表征技能,在纳米光电、纳米能源及其相关交叉领域从事科研、工程技术研发、应用和管理方面的工程技术人才或科技人才。

毕业生5年后能胜任技术主管工程师、研发团队骨干或项目管理工程师。具体细化为以下5个方面:

(一)能够自觉践行社会主义核心价值观,具备良好的思想品德、人文素养、职业道德和社会公德等综合素质的德智体美劳全面发展的社会主义建设者和接班人。(二)能在工业界、学术界与教育界成功地开展与专业职业及创新性技术研发相关的工作,适应独立和团队工作环境,并能以服务社会、忠诚担当的责任意识,在团队中发挥骨干作用。(三)能够在社会与科技大发展的背景下理解和解决纳米材料与技术工程实践的问题,并能选择合适的技术或工具针对性地解决工程问题。(四)能够通过终身学习并适应职业可持续发展,在纳米材料与技术专业领域具有职场竞争力,能够进一步深造成为相关行业高级人才。(五)具有国际视野,能够积极主动适应不断变化的国内外形势和环境,拥有自主的、终生的学习习惯和能力。

## 二、毕业要求

纳米材料与技术专业的学生在毕业时能够牢固树立正确的祖国观、民族观、历史观、文化观和宗教观,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。在此基础上满足以下12条毕业要求:

(一)工程知识:能用数学、物理、化学及相关专业知识描述工程实践中纳米材料设计、制备及器件应用之间的复杂关系,并能够将数学、物理、化学及工程专业知识用于解决纳米材料与技术领域的复杂问题。

(二)问题分析:具备利用自然科学原理理解纳米材料与技术工程问题的能力,掌握识别、表达、分析相关工程问题的科学方法;能够运用数理化和工程基础知识,理解纳米材料结构与性能相互影响的复杂关系。能具有运用现代信息技术获取新知识的能力,能够识别、表达、并通过文献调研分析纳米材料与技术领域的复杂问题。(三)设计/开发解决方案:能够针对纳米材料与技术领域中结构与性能之间的复杂问题,设计出具体的解决方案,并在纳米材料与器件设计环节中体现创新意识,在设计环节中能够考虑多因素交互作用,体现创新意识,考虑社会、健康、安全、法律、文化以及环境等因素。(四)科学研究:能够基于科学原理并采用科学方法对纳米材料设计、制备及器件应用领域中的复杂问题进行研究,包括设计实验、分析与解释数据,并通过信息综合得到合理有效的结论。(五)使用现代工具:能够开发、选择与使用恰当的技术、资源、现代工程工具和信息技术工具,用于解决纳米科技领域的复杂问题。(六)工程与社会:能够恰当评价纳米材料与技术中的复杂问题的解决方案对社会、健康、安全、法律以及文化的影响,并理解其中应承担的责任。(七)环境和可持续发展:了解与纳米材料与技术相关行业的生产、设计、研究与开发、环境保护和可持续发展等方面的方针、政策和法律、法规,能够理解和评价复杂问题的解决方案对环境、社会可持续发展的影响。(八)职业规范:具有人文社会科学素养、社会责任感,能够在纳米材料与技术领域的实践中理解并遵守职业道德和规范,履行相关责任。(九)个人和团队:具有一定的组织管理能力、表达能力、独立工作能力和团队合作能力,理解团队中不同角色的作用,能够在多学科背景下的团队中承担个体、团队成员以及负责人的角色。(十) 沟通与交流: 能够就纳米材料与技术领域的复杂问题与业界同行及社会公众进行有效沟通和交流,包括撰写报告、设计文稿、陈述发言。具备国际化视野,能够在跨文化背景下进行沟通和交流。

(十一)项目管理:理解并掌握工程管理原理与经济决策方法,并能在纳米材料与技术领域中应用。(十二) 终身学习: 对终身学习有正确认识, 具有自主学习和终身学习的意识, 有不断学习、持续提高自己和适应发展的能力。

### (三)个性化培养

为充分对接学生未来发展、满足学生个性化选择,设置本硕贯通课程、跨学科交叉课程、全球胜任力培养课程和行业领域协同育人课程,学生可根据未来发展意向选择修读相关课程,此部分至少修读6学分。

修读建议如下:

1. 拟继续深造学生建议选择修读本硕贯通专业选修课程。免试推荐攻读本校研究生的本科生可提前学习研究生课程,并计入研究生学分。
2. 拟出国学生建议选择修读全球胜任力培养课程,包括全英文科技前沿课程、国际课程、全球胜任力微专业课程,也可通过境外访学进行国际学分转换。
3. 拟就业学生建议选择行业领域协同育人课程修读,针对未来职业选择修读相应的课程。
4. 学生可根据个人发展需要,选择列表中跨学科交叉课程,也可跨专业选修其他专业设置的专业课程。

### (四) 实践环节

实践环节包括专业实践、社会实践和创新创业实践,必修17学分。

#### 1. 专业实践

专业实践包括学年论文、专业实习、毕业设计等,必修13学分。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业设计|6|必修|7-8|
|毕业实习|3|必修|/|
|学年论文|1(18学时)|必修|/|
|金工实习|1.5|必修|2|
|电子工艺实习|1.5|必修|3-4|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少10次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。

## 七、其他说明

允许国际学分、在线课程学分、创新创业奖励学分、联盟高校学分、第二课堂社团等学分转换。创新创业实践学分可转换为综合素养学分(最多可转换4个学分),学校大学生艺术团团员可根据艺术团性质免修相应综合素养课程模块的2个学分,学校体育运动队队员可免修“大学体育”公共必修学分。
