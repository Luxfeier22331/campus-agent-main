## 一、培养目标

金融学专业二学位培养政治立场坚定、综合素质优异、经济理论扎实,具有强烈社会责任感、深厚家国情怀、宽广国际视野,掌握经济学基础、金融学专业知识和相关技能,具备金融
及相关专业交叉研究能力和创新创业能力,胜任高等院校、国家机关、国际机构和组织以及经济金融相关领域企事业单位的高素质综合性人才。

,为必修。

### (二)专业实践

专业实践包括学年论文和毕业论文,必修7学分。

学年论文一般不少于8000字,需有完整的文献综述和研究设计,可作为毕业论文的预研究,第3学期开学后提交。

675毕业论文一般不少于 10000 字, 需使用规范的经济学研究方法, 完成开题报告, 毕业论文写作并通过论文答辩。
