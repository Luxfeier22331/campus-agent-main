## 一、培养目标

本专业培养践行社会主义核心价值观,具有社会责任感、公共意识和创新精神,系统掌握经济学原理与方法,精通财政学基本理论,了解财政学科前沿和发展动态,熟悉国家财政、税收相关制度、政策和法规,具备财税实际业务技能的创新型专门人才,能够在财政税务政府机关、其他公共管理部门、工商企业、金融机构、事务所等从事财税决策、管理、筹划、咨询、研究等工作,也可以进入国内外高校、科研机构,继续本专业或相关专业的学习与深造。

## 二、毕业要求

### (一) 素质要求

1. 政治素质:牢固树立正确的国家观、民族观、历史观和文化观,对中国共产党和中国特色社会主义高度认同,具有维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。
2. 专业素质:学会用财政学思维审视、分析国家治理、公共经济和财政税收等理论与现实问题,学会使用财政学方法和技术,处理政府、企业、金融机构以及中介组织涉税、涉财业务。
3. 综合素质:自觉践行社会主义核心价值观,具有良好思想品德、职业道德和社会责任意识,掌握基本的现代信息技术,具有国际视野和跨文化交流能力,热爱劳动,身心健康。

### (二)知识要求

1. 通识性知识:包括自然科学、社会科学、人文艺术等知识,实现学生“宽口径、厚基础”全面发展。
2. 专业性知识:以经济学理论、方法学习为主,了解管理学、法学、社会学、历史学等相关学科知识,理解财政学的跨学科属性;在经济学大类培养的基础上,聚焦财政学专业知识学习,站在“财政是国家治理的基础和重要支柱”高度,精通财政、税收、公债、公共投资、社会保障等领域的专业知识。

3. 工具性知识:学习文献检索、社会调查、数据处理、学术论文写作等知识,精通现代经济分析方法,熟练运用主流社会经济统计软件。

### (三)能力要求

1. 业务能力:能综合运用财税专业知识,胜任财税管理、税收筹划、税务代理、公共投资、财务会计等各类业务。
2. 科研能力:了解财政学专业及相关领域国内外前沿动态,能综合运用经济学、财政学理论方法,对财税问题进行学理性分析,并提出解决方案或政策建议。
3. 创新能力:养成探究性学习习惯和创新性思维,开展科研训练和竞赛活动,具有良好的实际动手和解决复杂问题的能力,具备“敢闯会创”的创新创业精神。
4. 其他能力:具备较强的中文表达能力、外语能力、人际沟通和团队协作能力以及对计算机、数字信息技术的应用能力等。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、专业实习或毕业实习、毕业论文(设计)等,必修10学分。

学年论文一般不少于 8000 字,需有完整的文献综述和研究设计,可作为毕业论文的预研究,四年级开学后提交。

毕业论文一般不少于 10000 字,需使用规范的经济学研究方法,要完成开题报告、毕业论文写作与通过论文答辩。

毕业实习时间累计不少于8周,最终提交实习报告和实习证明。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|3|必修|/|
|学年论文(设计)|1(18学时)|必修|/|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。
