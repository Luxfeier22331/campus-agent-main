## 一、培养目标

本专业类聚焦国家战略与区域经济社会发展对统计学人才的需求,以强数学基础、重专业实践为指导思想,培养具有过硬的政治素质、深厚的家国情怀、宽广的国际视野、良好的综合素养、坚实的数学学科基础,较强的统计方法、数据处理的研究和应用能力,能够在大数据与人工智能时代的统计与数量分析行业从事专业技术和管理等工作的实用型和通用型人才。

毕业生能在经济、管理、金融、医学、生物、工程、环境等部门从事统计调查、统计信息管理、数量分析等工作,或在涉及大数据分析的企事业单位从事统计分析和咨询等工作,或在科研、教育部门从事研究和教学工作。毕业生可继续攻读统计学研究生学位,还可选择攻读数学、计算机和经济管理类研究生学位。

## 二、毕业要求

### (一)素质

1. 政治素质:热爱社会主义祖国,拥护中国共产党,具有良好的政治思想素质、道德品质、法治意识、诚信意识和团队合作精神,能自觉践行社会主义核心价值观,具有中华民族共同体意识。
2. 思想品德:具有良好的思想品德、职业道德和社会责任意识,具有良好的心理素质和积极的人生观。
3. 综合素养:拥有一定的人文素养和艺术鉴赏能力,熟练使用现代信息技术和一门外语,热爱劳动,身心健康,富有创新精神。
4. 职业素养:具有健全的职业人格,热爱统计学事业,拥有严谨的科学思维,具备科学的统计思想,具有严谨治学、艰苦奋斗、求新务实的精神。
5. 国际视野:了解国内外统计工作中常用方法与工具,具备跨文化沟通能力。

### (二)知识要求

1. 学科基础与理论:具有扎实的数学基础,掌握统计学的基础理论。
2. 专业核心知识:掌握基础数学、概率论与数理统计、运筹与优化等基本理论与方法。
3. 研究方法:掌握文献检索、资料查询、收集数据的基本方法,并能够根据数据的特点选用恰当的统计方法进行分析和推断。
4. 学科前沿:了解统计学理论、技术及应用领域的最新发展动态。
5. 跨学科知识:应用统计学专业掌握经济学和金融学等知识。

### (三)能力要求

1. 应用能力:能熟练使用计算机常用语言、工具及专业统计软件,具有一定的算法设计、算法分析与编程能力,能正确利用统计思想和方法分析判断软件的计算结果,具有一定的软件开发能力。
2. 专业能力:掌握经济学和金融学的基本知识和基本理论,具备运用统计知识进行经济与金融问题分析的能力,能运用所学的理论、方法和技能解决政府部门、金融或经济等应用领域中的实际问题。
3. 科学研究能力:能够对实际领域出现的统计学问题或数据分析问题开展研究性工作。
4. 团队合作能力:能够在多学科背景下的团队中承担个体、团队成员和团队负责人的任务。
5. 创新能力:具备自主学习、知识更新和终身学习意识,具有理论联系实际的能力,针对实际问题进行分析和研究的创新能力。

### (二)专业实践

专业实践包括学年论文、专业实习、毕业论文等,必修学分10学分。专业实习与毕业论文要符合学校相关规定。专业实习一般在第3学期至第4学期之间进行,要求学生在企业或事业单位从事与专业有关的工作,实习时间至少15天,有实习单位出具证明。
