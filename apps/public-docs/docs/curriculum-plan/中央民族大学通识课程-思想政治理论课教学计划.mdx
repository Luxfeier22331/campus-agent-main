---

思想政治理论课(简称“思政课”)是落实立德树人根本任务的关键性课程,是培养学生树立崇高理想信念的主渠道。根据教育部印发的《新时代高校思想政治理论课教学工作的基本要求》(教社科〔2018〕2号)和国家关于铸牢中华民族共同体意识教育的相关要求,学校除开设马克思主义基本原理、中国近现代史纲要、毛泽东思想和中国特色社会主义理论体系概论、习近平新时代中国特色社会主义思想概论、思想道德与法治、形势与政策等6门思政课外,还开设一门特色思政课“中华民族共同体概论”。

教学安排和计划如下:

## 一、教学目标

通过系统学习马克思主义基本立场、观点和方法,以及中国特色社会主义理论与实践体系,培养学生运用马克思主义理论分析研究历史与现实问题的思维习惯和能力,提升理论素养和道德修养,强化使命担当,引导学生树立正确的世界观、人生观、价值观和马克思主义国家观、民族观、历史观,铸牢中华民族共同体意识,全面增强学生对中国特色社会主义道路自信、理论自信、制度自信、文化自信,和对伟大祖国、中华民族、中华文化、中国共产党、中国特色社会主义道路的认同,争做社会主义合格建设者和可靠接班人。

## 二、课程设计

### (一)课程内容

思政课教学内容按照教育部相关要求,均使用“马工程”教材或讲义。

1. 马克思主义基本原理:学习和掌握马克思主义的基本原理与马克思主义的基本立场、观点和方法,运用马克思主义的世界观和方法论观察和分析问题,培养和提高学生运用马克思主义理论分析和解决实际问题的能力,为学生确立建设有中国特色社会主义的理想信念,自觉地坚持党的基本理论、基本路线和基本纲领打下扎实的理论基础。

2. 毛泽东思想和中国特色社会主义理论体系概论:学习和掌握马克思主义中国化理论成果的主要内容、精神实质、历史地位和指导意义,充分反映中国共产党不断推进马克思主义基本原理与中国具体实际相结合的历史进程和基本经验。以马克思主义中国化最新成果为重点,全面把握中国特色社会主义进入新时代,系统阐释习近平新时代中国特色社会主义思想的主要内容和历史地位,充分反映建设社会主义现代化强国的战略部署。

3. 中国近现代史纲要:掌握中国近现代史的基础知识,把握中国近现代史的基本线索及发展规律;了解中国共产党人实现马克思主义基本原理与中国具体实际相结合第一次历史性飞跃及其理论成果,增强建设中国特色社会主义的自觉性,充分认识社会主义改造以后中国现代化建设事业的发展尤其是改革开放以来取得的巨大成就,懂得中国选择社会主义的正确性。

4. 思想道德与法治:以马克思列宁主义、毛泽东思想、中国特色社会主义理论体系为指导,综合运用马克思主义的基本立场、观点和方法,引导解决大学生成长过程中面临的思想道德和法律问题。依据大学生成长成才规律,通过理论学习和实践体验,教育、引导大学生加强世界观、人生观、价值观、道德观和法治观的修养,全面提高大学生的思想道德素质、行为修养和法律素质。

5. 形势与政策:依据教育部每学期印发的《高校“形势与政策”课教学要点》安排教学,根据形势发展要求和学生特点有针对性地设置教学内容,紧密围绕学习贯彻习近平新时代中国特色社会主义思想,把坚定“四个自信”贯穿教学全过程。通过对国内外形势和国家大政方针的学习和研讨,使大学生正确认识新时代国内外形势,深刻领会党的十八大以来党和国家事业取得的历史性成就。

6. 习近平新时代中国特色社会主义思想概论:理解和掌握习近平新时代中国特色社会主义思想的核心要义、精神实质、丰富内涵、实践要求。深入领会其时代意义、理论意义、实践意义、世界意义,深刻把握其贯穿的马克思主义立场、观点、方法,进一步增强“四个意识”、坚定“四个自信”、做到“两个维护”,不断提高马克思主义理论素养和理论水平,增进政治认同、思想认同、情感认同,努力成长为担当复兴大任的时代新人。

7. 中华民族共同体概论:学习和掌握运用唯物史观分析中国共产党民族理论发展中的一些大事件,掌握中国共产党民族理论发展的历史进程及其内在的规律性。培养各民族学生的中华民族共同体意识;增强学生的“五个认同”,能运用多元一体理论分析中华民族的发展,能用法制意识和法制思维去评析民族问题、民族现象。了解习近平总书记关于民族工作的重要论述,认识和理解“铸牢中华民族共同体意识”的深刻内涵与必要性。

### (二)教学方式

学校全面推进思政课教学方式改革,实施理论+实践、线上线下混合式教学、分级推进与分类教学、全校共上一堂思政课的教学方式改革。

1. 马克思主义基本原理:坚持分类教学原则,采用课堂讲授、课下实践、小组研讨、观看视频教学片和片段、体验式教学等多种教学方式和方法进行课程教育教学。尤其注重在中国少数民族语言文学部分方向、民族班和艺术体育类专业中实施实践教学改革,通过学生理论学习与专业知识相结合的方式展示教学成果。
2. 毛泽东思想和中国特色社会主义理论体系概论:采取课堂教学、慕课与实践教学相结合的方式。实践教学按照分类教学原则采取多样化形式,鼓励学生以专业作品展示理论学习心得,进而加深对中国特色社会主义理论的理解。
3. 中国近现代史纲要:将理论讲授、线上学习与实践教学有机结合,强化实践教学,充分利用北京红色资源和学校特色优势,开展爱国主义、“四史”和民族团结教育实践教学。
4. 思想道德与法治:采取专题教学与实践教学相结合的方式。实践教学以理论教学内容为根据,坚持校内和校外相结合、思政教育和专业教育相结合,采取教师集中组织和学生分散进行两种形式。校外实践项目包括参观感受类、调研分析类、采访任务类等三类,校内实践项目包括课外阅读类、成长体验类、情感情境体验类、教学参与类、课题研究类、志愿服务类等六类。

5. 形势与政策:实施分级分类教学方式,针对一-二年级学生采取“线上慕课”+“X”(一般为万人共上一堂课)方式,针对大三年级学生采取“实践教学”+“翻转课堂”方式,针对大四年级学生采取“社会实践”方式。
6. 习近平新时代中国特色社会主义思想概论:按照分类教学原则,采取将系统讲授与实践教学相结合的方式。前14讲为理论学习,后2讲为“习近平新时代中国特色社会主义思想在京华大地的生动实践”案例教学,并且将北京市“12345热线平台”作为案例教学的基地。
7. 中华民族共同体概论:采取“线上”和“线下”混合式课堂教学方式,在学生线上学习的基础上,教师引导梳理线上学习内容,解答学生线上学习的问题,深化议题中的相关内容,学生就相关议题进行讨论、交流、汇报、展示。

## 三、修读要求

为全校性公共必修课,合计19学分,所有本预科学生应认真完成上述7门课程设置的各教学环节,获得要求学分。

## 四、学业评价方式

思想政治理论课程已形成各具特色的学业评价方式。各门课程除理论知识考核评价外,尤其注重实践教学内容之评价,实践教学学业评价以理论知识运用与学生专业特长相结合为原则,采取多样化方式。

- 课程名称：马克思主义基本原理
  - 学业评价方式：采用平时+期中+期末综合考核方式: 1.平时考核:课堂考勤、讨论、作业等; 2.期中考核:文理类采取读书报告形式或调查报告形式;加测民族语和艺体类采取多样考核形式; 3.期末考核:以统一考试(试卷题型)为主,特殊情况采取期末论文的形式。 各考核所占比例: 文理类:平时成绩40%+期中成绩20%+期末成绩40%;加测民族语和艺体类:平时成绩30%+期中成绩30%+期末成绩40%。

- 课程名称：毛泽东思想和中国特色社会主义理论体系概论
  - 学业评价方式：总评成绩=平时考核(30%)+期中考核(30%)+期末考核(40%); 1.平时考核:包括考勤、课堂讨论、课堂作业等; 2.期中考核:大学生讲思政课(微电影)、艺术作品、调查报告等; 3.期末考核:随堂测试或论文。

- 课程名称：中国近现代史纲要
  - 学业评价方式：总评成绩=平时考核(30%)+期中考核(30%)+期末考核(40%); 1.平时考核:考勤、讨论、平时作业等; 2.期中考核:实践作品+实践论文; 3.期末考核:卷面考试,卷面成绩构成:单选题40分,多选题40分;论述题20分。

- 课程名称：思想道德与法治
  - 学业评价方式：理工类:平时成绩30%+期中成绩30%+期末试卷成绩40%;艺体类和加测民族语类:平时成绩30%+期中成绩30%+期末试卷成绩40%。 1.平时成绩=出勤成绩×30%+随堂问答×50%+提问式作业×10%+线上作业×10% 2.期中成绩=实践汇报展示成绩×60%+实践作业成绩×40% 3.期末成绩:思想专题综合分析题1题35分,道德专题综合分析题1题30分;法律专题综合分析题1题35分,总计100分。

- 课程名称：形势与政策
  - 学业评价方式：1.实行学期考核制度,每学期考核一次; 2.成绩计算方式:课程学习+课程作业; 3.成绩评定方式:依据学生各学期考核情况综合评定。

- 课程名称：习近平新时代中国特色社会主义思想概论
  - 学业评价方式：本课程注重过程考核与综合考核。成绩评定采用平时考核30%(课堂考勤、课堂互动讨论、经典阅读等)+期中实践30%(实践报告或读书报告)+期末考核40%(知识测试或课程论文)的方式进行。

- 课程名称：中华民族共同体概论
  - 学业评价方式：总评成绩=慕课成绩50%+期中成绩20%+期末成绩30%。 1.慕课成绩:要求学生在规定的时间内自主学习; 2.期中成绩:考核小组合作、学习内容与专业结合情况; 3.期末考试:手绘慕课某课内容知识结构图+随堂主观题考试。

## 五、其他说明

1. 哲学和宗教学专业不开设“马克思主义基本原理”课程。
2. 历史学专业不开设“中国近现代史纲要”课程。
