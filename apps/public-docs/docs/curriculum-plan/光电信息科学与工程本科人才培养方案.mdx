## 一、培养目标

本专业依据新时期中国特色社会主义事业所需合格建设者和接班人的培养总要求,聚焦国家战略和区域经济社会发展对光电信息科学与工程人才的需求,培养德、智、体、美、劳全面发展,具有过硬的政治素质、深厚的家国情怀、宽广的国际视野、良好的综合素养,以及数理基础扎实,专业知识宽厚,专业软件应用与工程实践能力突出,能够胜任光学成像与处理、光电子器件、光信息和光传感及其相关领域的科研、工程技术研发、应用和管理工作的高层次专门技术人才。

毕业生毕业后5年左右应预期达到:

(一)具有履行工程伦理道德责任和尊重社会价值的能力,并能承担推动社会、经济、科技可持续发展的责任。(二)具有理解、分析和解决光电信息及相关领域复杂工程问题的能力,能胜任光电器件与系统的分析、设计、运行及开发工作,取得工程师资格或具备同等职业能力。(三)具有发现问题、解决问题的创新思维和能力,能够胜任光电信息科学与工程领域的前沿科学研究工作,成为所在单位技术骨干。(四)具有良好的思想品德和人文素养,身心健康,沟通能力强,具有领导、组织多学科背景团队协作共同完成光电信息科学与工程及相关领域复杂工程项目的能力。(五)具有国际视野和跨文化交流、竞争与合作能力,熟知光电信息领域及其相关行业的发展动态,拥有自主的、终生的学习习惯和能力。

## 二、毕业要求

光电信息科学与工程专业的学生在毕业时能够牢固树立正确的祖国观、民族观、历史观、文化观和宗教观,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结与祖国统一的使命感,铸牢中华民族共同体意识。在此基础上满足以下12条毕业要求:

(一) 工程知识: 能够将数学、自然科学、工程基础和专业知识用于解决光电信息科学与工程领域相关复杂工程问题。

(二)问题分析:能够应用数学、自然科学和工程科学的基本原理,识别、表达、并通过文献研究分析光电信息领域的复杂工程问题,以获得有效结论。

(三)设计/开发解决方案:能够设计针对光电信息工程相关复杂工程问题的解决方案,设计满足特定需求的光电信息系统、单元(部件)或工艺流程,并能够在设计环节中体现创新意识,考虑社会、健康、安全、法律、文化以及环境等因素。

(四)研究:能够基于科学原理并采用科学方法对光电信息领域的复杂工程问题进行研究,包括设计与开展实验、软硬件调试、器件制备与数据分析解释,并通过信息综合得到合理有效的结论。

(五)使用现代工具:能够针对光电信息领域的复杂工程问题,开发、选择与使用恰当的技术、资源、现代工程工具和信息技术工具,包括对复杂工程问题的预测与模拟,并能够理解其局限性。

(六)工程与社会:能够基于光电工程相关背景知识进行合理分析,评价光电专业工程实践和复杂工程问题解决方案对社会、健康、安全、法律以及文化的影响,并理解应承担的责任。

(七)环境和可持续发展:能够理解和评价针对光电信息复杂工程问题的工程实践对环境、社会可持续发展的影响。

(八)职业规范:具有人文社会科学素养、社会责任感,能够在工程实践中理解并遵守工程职业道德和规范,履行责任。

(九)个人和团队:能够在多学科背景下的团队中承担个体、团队成员以及负责人的角色。

(十)沟通:能够就光电信息技术与系统相关复杂工程问题与业界同行及社会公众进行有效沟通和交流,包括撰写报告和设计文稿、陈述发言、清晰表达或回应指令,具备一定的国际视野,能够在跨文化背景下进行沟通和交流。

(十一)项目管理:理解并掌握光电信息领域工程管理原理与经济决策方法,并能在多学科环境中应用。

(十二) 终身学习: 具有自主学习和终身学习的意识, 有不断学习和适应发展的能力。

### (三)个性化培养

为充分对接学生未来发展、满足学生个性化选择,设置本硕贯通课程、跨学科交叉课程、全球胜任力培养课程和行业领域协同育人课程,学生可根据未来发展意向选择修读相关课程,此部分至少修读6学分。

修读建议如下:

1. 拟继续深造学生建议选择修读本硕贯通专业选修课程。免试推荐攻读本校研究生的本科生可提前学习研究生课程,并计入研究生学分。
2. 拟出国学生建议选择修读全球胜任力培养课程,包括全英文科技前沿课程、国际课程、全球胜任力微专业课程,也可通过境外访学进行国际学分转换。
3. 拟就业学生建议选择行业领域协同育人课程修读,针对未来职业选择修读相应的课程。
4. 学生可根据个人发展需要,选择列表中跨学科交叉课程,也可跨专业选修其他专业设置的专业课程。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践,必修17学分。

#### 1. 专业实践

专业实践包括学年论文、专业实习、毕业设计等,必修13学分。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业设计|6|必修|7-8|
|毕业实习|3|必修|/|
|学年论文|1(18学时)|必修|/|
|金工实习|1.5|必修|2|
|电子工艺实习|1.5|必修|3-4|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少10次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|/|
|学术讲座报告|0.5|必修|/|
|第二课堂(志愿服务、文体活动等)|0.5|必修|/|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程2学分。
