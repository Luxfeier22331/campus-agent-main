## 一、培养目标

秉承“立德启智、知行合一、文化融合、国际视野”的育人理念,立足北京,面向全国,着眼国际,主要培养政治素质过硬、人文底蕴深厚、国际视野宽广、教育学理论基础扎实、实践能力突出、创新理念先进、道德品质高尚、具有强烈家国情怀、热爱教育事业的教育学研究和应用的复合型人才。学生未来可以胜任教育教学、教育管理、教育研究、教育与心理咨询、教育创业等工作。

目标1:培育优良师德师风意识。提高政治素养,拥护中国共产党的领导和中国特色社会主义制度,铸牢中华民族共同体意识;拥护党和国家的教育方针、政策、理念,遵守教育法律法规,具有良好的道德品质,树立正确的世界观、人生观和价值观,遵纪守法,自觉遵循为人师表、以身立教的职业操守,具有强烈的教育责任感和使命感,热爱教育事业。

目标2:掌握教育专业基础知识。掌握教育学专业和相关领域的基础知识、基本理论和基本技能;熟悉教育发展的基本原理与规律;具备多学科知识基础和深厚的文化修养;具备较强的本专业外文听说读写能力。

目标3:增强教育教学实践能力。能够开展中小学学科教学;熟练掌握信息化教学技能,根据学科内容,使用现代教育技术手段进行教学设计并实施教学活动;能够根据实际情况开展教育管理工作;并能够针对学生学习过程中出现的问题提供教育咨询;能够胜任教育企事业单位的教学产品开发、教学环境设计等工作。

目标4:提高教育科学研究水平。热爱教育科学研究工作,熟练掌握教育科学主要研究方法,能够进行文献信息检索和数据处理,具有独立发现问题、提出问题、分析问题和解决问题的基本能力;了解国内外教育发展动态与趋势,能较为熟练地开展专业领域内的学术交流,具有对跨文化教育和国际教育的基本理解和认识能力。

目标5:筑基个人综合品行素养。能够深入了解创新创业相关知识,热爱劳动,具备强健的体魄和健康的心理,形成良好的审美素养、高尚的艺术情趣、健全的人格和优秀的品质,具有较强的创新创业精神和教育创业实践能力。

## 四、各教学环节、学时和学分

教育学专业本科修读阶段分为大类培养、专业培养和个性化培养阶段。大类培养阶段,主要开展通识教育和学科基础教育,合计74学分,其中必修66学分,选修8学分。专业培养阶段,主要开展专业教育,合计49学分,其中必修25学分,选修24学分。个性化培养阶段,主要开展个性化教育,合计6学分,均为选修学分。实践环节包括创新创业实践,专业实践和社会实践,合计20学分,均为必修学分。四个阶段的总学分149学分。

### (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

#### 1. 专业实践

专业实践包括学年论文、毕业见习和实习、毕业论文(设计)等,必修16学分。其中毕业见习分散在各个学期,毕业实习时间为4周,由校外一线教师和校内专任教师共同指导,要求学生提前拟定见习、实习研习计划,做好见习、实习工作记录、撰写见习、实习报告。毕业论文(设计)时长不少于8周,要求学生在教师的指导认真撰写毕业论文,论文答辩不合格者不能取得毕业资格。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文(设计)|6|必修|7-8|
|毕业实习|6|必修|6-7|
|毕业见习|3|必修|3-7|
|学年论文(设计)|1(18学时)|必修|6-7|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少6次,积极参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|1-7|
|学术讲座报告|0.5|必修|1-7|
|第二课堂(志愿服务、文体活动等)|0.5|必修|1-7|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,其余学分可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合素养课中相应类别课程的2学分。
