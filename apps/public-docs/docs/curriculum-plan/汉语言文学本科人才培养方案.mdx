## 一、培养目标

汉语言文学专业以马克思主义为指导,培养政治素质过硬、人文素养深厚、学风严谨、基础扎实、具备系统的中国语言文学专业知识、突出的创新能力、实践能力和竞争能力,能够从
事教学、科研、管理和文化宣传等适应时代发展与社会广泛需要的高素质人才。

### (三)个性化培养

为充分对接学生未来发展、满足学生个性化选择,设置本硕贯通课程、跨学科交叉课程、全球胜任力培养课程和行业领域协同育人课程,学生可根据未来发展意向选择修读相关课程。
此部分至少完成6学分。修读建议如下:

拟继续深造学生建议选择修读本硕贯通专业选修课程。免试推荐攻读本校研究生的本科生可提前学习研究生课程,并分别计入本科生学分和研究生学分。

学生可根据个人发展需要,跨专业选修其他专业设置的专业课程。

拟就业学生建议选择行业领域协同育人课程修读,针对未来职业选择修读相应的课程。

## (四)实践环节

实践环节包括专业实践、社会实践和创新创业实践。

### 1. 专业实践

专业实践包括毕业论文、毕业实习和学年论文,必修学分10分。

|类别|学分|修读性质|学期|
|---|---|---|---|
|毕业论文|6|必修|7-8|
|毕业实习|3|必修|5-7|
|学年论文|1|必修|6|

#### 2. 社会实践

社会实践包括校级社会实践、学术讲座报告、参加志愿者服务、文体活动等,必修2学分。学生需要参加校团委组织的校级社会实践活动至少1次,参加学术讲座报告至少5次,积极
参加党和国家重大活动、挂职锻炼/就业实习、志愿服务、文体活动等,学分计算参照《中央民族大学大学生社会实践环节实施方案》实施。

|类别|学分|修读性质|学期|
|---|---|---|---|
|校级社会实践|1|必修|1-5|
|学术讲座报告|0.5|必修|1-7|
|第二课堂(志愿服务、文体活动等)|0.5|必修|1-7|

#### 3. 创新创业实践

创新创业实践包括参加创新创业项目、学科竞赛等,必修2学分。创新创业实践学分除必修2学分外,可转换为综合素养课中创新创业素养类课程的2学分,也可根据内容转换为综合
素养课中相应类别课程2学分。
