## 一、培养目标

### (一)专业类培养目标

以习近平新时代中国特色社会主义思想为指导,以立德树人为根本,以铸牢中华民族共同体意识为主线,以学生为中心,以音乐学院人才培养的“民族传统、变革创新”为本色,坚持“三个面向”——始终面向少数民族地区、始终面向少数民族音乐人才、始终面向少数民族音乐文化的传承发展,做好“两个服务”——服务于国家民族团结进步伟业与民族艺术繁荣发展、服务于首都“四个中心”的国家文化交流中心和民族文化艺术窗口,努力培养具有过硬政治素质、强烈社会责任感、深厚家国情怀、宽广国际视野、热爱民族音乐事业,音乐学科基础理论扎实、音乐专业知识完备、分别具备良好的表演技能、学术研究能力、音乐创作能力,及奋力进取的创新精神,适应相关专业工作需要的各民族优秀音乐人才。

### (二)各专业(方向)具体培养目标

#### 1. 音乐表演

培养具有扎实的表演或演奏基本功、鲜明的民族特色、良好的艺术实践能力,从事声乐专业演唱、乐器演奏和教学工作需要的应用型专门人才和少数民族声乐领域的杰出人才。

#### 2. 音乐学

音乐学:培养具有扎实的音乐学基础理论知识、多层知识结构、多元文化素养、富有创新能力,从事音乐学研究和教学工作需要的研究型兼应用型专门人才。

音乐学(音乐教育):培养具有扎实的音乐教育基础理论知识、多层知识结构、音乐教育的综合能力,从事音乐教育教学工作的应用型专门人才。

#### 3. 作曲与作曲技术理论

培养具有扎实的音乐创作基础理论知识、丰富的音乐创作方法、多种风格的创作能力,从事音乐创作和教学工作需要的应用型专门人才。

## 二、毕业要求

音乐学院各专业本科毕业生,必须达到国家标准和学校培养方案的要求,完成各自主修专业的总学分,应具备如下素养、知识和能力:

### (一)素质要求

1. 政治素质:牢固树立正确的祖国观、民族观、历史观、文化观和宗教观,对伟大祖国、中华民族、中华文化、中国共产党和中国特色社会主义高度认同,具有强烈的中华民族归属感、中华文化认同感、伟大祖国自豪感,和维护民族团结和祖国统一的使命感,铸牢中华民族共同体意识。

2 公民素养:具有良好的思想道德品质和社会公德,自觉遵守社会行为规范,积极践行社会主义核心价值观。

3. 职业素养:热忱对待音乐事业,乐于、甘于投身祖国的音乐事业。

4. 国际视野:具有宽广的国际视野、全球意识,养成兼容并蓄的心态,掌握国内外音乐发展前沿,积极、平等地参与国际化交流和跨文化沟通。

### (二)知识要求

1. 学科基础和理论:掌握音乐基础理论知识、视唱练耳能力、音乐分析基本理论、中国各民族传统音乐知识和中西方音乐史等。

2. 方法和技能:音乐表演专业应具备良好或优异的音乐表演技能;音乐学(含音乐教育)专业应具备深厚的学科基础、扎实的专业知识和研究方法,以及良好的教学实践能力;作曲与作曲技术理论专业应具备扎实的基本创作能力和多元风格的写作能力。

3. 学科前沿:了解各自专业发展的学科前沿动态,具有国际化意识与开放心态,积极探索音乐发展前沿。

4. 跨学科知识:具有宽广的通识知识,如哲学、历史等人文社科知识,以及具有跨学科知识,如音乐人工智能等新型高科技知识。

### (三)能力要求

1. 专业能力:音乐表演专业能够从事独唱(奏)、重唱(奏)、合唱(奏)等舞台表演,具有演绎不同音乐风格和音乐流派的能力,适应各类音乐艺术团体、音乐普及、美育教育等工作。音乐学专业具备相关学术研究能力,适应学校、艺术研究单位和文化机关等单位的教学、研究、编辑、管理等工作。作曲与作曲技术理论专业应具备多元风格的创作能力,适应艺术团体、传媒公司、艺术教育等单位的作曲相关工作。

2. 沟通协助能力:各专业能够对内有效开展协作与互动实践,具有团队精神,并具有对外专业领域的国际交流能力。

3. 创新能力:养成探究性学习和创新性思维习惯,能够参与竞赛活动和科研工作,乐于关注新事物、学习新方法,善于反思,能够提出解决问题的新思路和新模式,形成音乐学科各自专业所需的创新精神和创业实践能力。
