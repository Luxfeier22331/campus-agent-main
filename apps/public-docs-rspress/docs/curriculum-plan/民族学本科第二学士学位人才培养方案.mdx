## 一、培养目标

本专业培养毕业生掌握民族学(文化人类学)的基本理论与研究方法,以当代各民族的社会文化为重点研究对象,培养民族学、人类学专业知识扎实、综合素质较高的复合型、应用性人才。本专业毕业生掌握和具备实地调查和理论分析能力,熟悉中外民族文化概况;能够从事民族学、人类学及相关专业科研与管理、新闻出版与影视、文化资源开发管理、民族宗教管理、民族政策研究、物质与非物质文化遗产管理等方面的工作。

## 二、培养规格/标准

1. 热爱社会主义祖国,拥护中国共产党,具有良好思想品德、社会公德和职业道德,能自觉践行社会主义核心价值观,具有家国情怀和中华民族共同体意识。

2. 熟练掌握相关专业的基本理论、基本知识与基本方法,同时具备人文社会科学和自然科学的相关知识和方法。

3. 具有良好的中文语言和文字表达能力,熟练运用一门外语听、说、读、写,以及熟练使用计算机、信息技术应用的能力。掌握专业的基本方法和基本技能,具有独立获取知识、提出问题、分析问题和解决问题的基本能力与创新精神,既有从事本专业业务工作能力,又有较宽的基础、较广的适应性和较强的自我更新能力。在熟练掌握田野调查技术的基础上,能够对各种环境有较强的适应能力与分析能力。

4. 具有扎实的专业理论素质、熟练的实地调查素质、健全的心理素质和良好的身体素质。

## 三、主干学科

民族学、社会学

## 四、核心课程

民族学导论,人类学导论,中国民族志,中国民族学人类学史,民族学田野调查方法、世界民族研究专题,民族学人类学经典导读,婚姻家庭与亲属制度,民族理论与民族政策,宗教、社会与文化,当代人类学理论,社会研究方法,政治法律人类学,经济人类学

## 十、有关说明

1. 社会实践(社会实践报告):通过参与各类与专业相关的社会实践活动,撰写实践报告,不少于 3000 字。

2.讲座报告:第1-4学期每学期至少参加3次本专业组织的讲座,第4学期开学第三周提交参加讲座的签到表(主讲人、讲座题目、时间、地点),同时提交一份3000字左右与讲座有关的研究综述。
