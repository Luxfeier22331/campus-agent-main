## 一、培养目标

为服务国际人文交流,本专业培养对中国语言文化和中国国情有较全面的认知,具有较强的汉语运用能力、多元文化意识和跨文化交际能力,掌握基本的中国语言文化以及一定的教育学、心理学等相关学科知识,熟悉汉语作为第二语言教学的方法,具备汉语教师的基本素质,具有一定从事汉语教学的能力或运用汉语从事其他相关工作能力的应用型、复合型国际汉语人才。

基于以上培养目标,本专业实行“知行研+国际化”特色人才培养模式。“知”是培养学生掌握专业基础知识并形成基本技能的能力。“行”是培养学生将所掌握的基础知识和基本技能运用于人文交流及教学实践的能力。“研”是培养学生发现问题、思考问题的研究意识和解决问题的研究能力。“国际化”是培养学生的多元文化意识和跨文化的沟通交流能力,提升来华留学生的国际视野和全球胜任力。

## 二、毕业要求

### (一)综合素养

1\. 国际公民素养:具有良好思想品德和社会公德。

2. 中国国情知识:了解中华民族核心价值观,了解中国国情和有关政策、方针和法规,了解相关文化现象。

3. 信息素养:掌握基本的现代信息教育技术。

4. 人文交流素养:具有一定的国际视野和跨文化交际能力,具备从事国际人文交流的基本能力。

### (二)专业能力

1. 汉语能力:具有较高的听、说、读、写、译能力,能够正确、流利、得体地运用汉语进行交际。本科毕业时,应该通过HSK最高等级的考试。(注:目前HSK最高等级考试为HSK6级,学生毕业时应达到HSK6级220分以上。)2. 学科核心知识:掌握中国语言文学和教育学学科专业基础知识,初步掌握汉语教学的基本理论和教学方法,了解心理学、文化学相关知识。

3. 实践能力:具备一定的汉语教学能力和组织管理能力,基本具备开展汉语教学、组织相关活动的能力。

4.研究方法:基本掌握本领域必备的研究方法。

### (三)创新能力

1. 养成探究性学习和创新性思维习惯,能够参加学科相关竞赛及科研活动;

2. 能够根据实践情况开展富有国别特色的国际人文交流活动;

3. 具有良好的解决汉语国际教育领域问题的实践能力。

## 七、其他说明

### (一)个性化定制学习计划

允许学生个性化定制学习计划。入学时汉语水平明显超过平均水平的学生(HSK6级180分以上)可直接学习本科二年纪课程。少数民族语言课程作为特色课程,开放给汉语水平较高的来华留学生(HSK6级250分以上)选修。

### (二)关于专业限定选修课

专业限定选修课属于本专业应完成的专业基础课程,如 HSK6 级达 220 分以上则可以选修其他课程学分抵扣。
