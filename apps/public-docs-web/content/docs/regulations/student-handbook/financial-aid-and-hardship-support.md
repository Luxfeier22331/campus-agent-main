## 一、适用范围

本指引适用于国家奖学金、国家励志奖学金、国家助学金及临时困难补助等资助事项的办理说明。

## 二、申请准备

申请前通常需要准备以下材料：

- 本人基础身份信息
- 家庭经济困难情况说明
- 相关证明材料
- 学院要求的补充表单

## 三、提交与审核

学生应在规定时间窗内通过学院通知渠道完成提交。学院完成初审后，学生处按规定流程进行复核、公示与归档。

- 清单结构在 Markdown 中的表现
- 高频事务入口对搜索的依赖
- 用户是否能从首页快速进入具体办理说明
