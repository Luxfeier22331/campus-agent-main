## 一、注册与课程确认

学生应当在每学期开学注册周内完成注册和课程确认。未按规定完成注册且未履行请假手续的，学校可依学籍管理办法做相应处理。

课程确认阶段应重点核对：

- 必修课是否全部进入个人课表
- 限选课和通识课的学分结构是否达标
- 是否存在考试时间冲突或培养方案冲突

## 二、缓考、补考与重修

因考试冲突、身体原因等情形申请缓考的，应当在考试前提交申请并上传证明材料。审批通过后，由学院统一安排后续考试。

补考、重修与正常修读是三种不同语义：

- 补考用于处理原课程考核未通过但允许参加统一补考的情形
- 重修用于课程重新学习与重新考核
- 正常修读则表示仍在原定培养进度中

文档站在这一类制度文档上，需要让用户快速定位到稳定章节，而不是只看到零散搜索片段。

## 三、学分预警与学业帮扶

当学生在某学期或某学年内累计学分完成情况明显偏离培养要求时，应纳入学业预警范围。学院和相关部门应提供阶段性帮扶建议，并明确后续修读安排。
