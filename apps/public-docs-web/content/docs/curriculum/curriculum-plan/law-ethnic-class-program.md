## 一、培养目标

本专业面向民族地区法治建设与公共治理需求，培养具备法学基础理论、法律实务能力与跨文化理解能力的复合型人才。

## 二、毕业要求

学生毕业时应满足以下条件：

- 完成培养方案规定学分
- 满足通识教育与专业核心课程要求
- 完成实践教学、毕业论文等必修环节

## 三、课程结构

课程结构通常分为：

- 通识教育课程
- 学科基础课程
- 专业核心课程
- 专业拓展课程
- 实践教学环节

## 四、第四学期样例

第四学期可以作为搜索与章节跳转测试段：

- 民法总论
- 刑法总论
- 行政法与行政诉讼法
- 法理学专题研讨

这一段适合验证“搜索命中某个学期课程列表后，能否顺利落到正文相应位置”。
