## 一、专业定位

本专业聚焦计算系统、软件工程、数据智能与工程实践，强调基础能力、系统实现能力和持续学习能力。

## 二、能力要求

学生应具备：

- 计算思维与系统分析能力
- 软件设计、开发与测试能力
- 数据处理与智能应用能力
- 工程协作与项目交付能力

## 三、实践教学

培养过程中需结合课程实验、课程设计、专业实习和毕业设计等实践环节，形成完整的工程训练链路。
