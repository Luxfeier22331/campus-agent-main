## contact_directory collection config

This directory holds the repo-tracked offline-only config scaffolding for the
`contact_directory` collection within the `campus_services` corpus.

- `runtime-profile.json`: canonical runtime gate for offline ingestion only

`contact_directory` is the long-term home for structured campus contact content such
as handbook-derived phone pages and future campus contact directories. It is not part
of the default phase-1 query-serving scope.
