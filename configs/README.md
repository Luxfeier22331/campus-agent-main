# 配置目录

本目录只保存当前代码或构建链实际消费的、环境无关的输入。

## 目录边界

- `runtime/`：已部署程序读取的运行时配置；每个 JSON 必须登记到合同 schema 注册表并有当前消费者。
- `sources/`：多个模块共享的非敏感来源描述；凭据、环境仓状态和采集产物不进入这里。
- `ingestion/`：离线采集任务的环境无关 profile、注册表和合成样例；collection 配置必须有当前任务
  注册和消费者，不保存待启用目标或在线路由。

应用静态资源归属具体应用，测试夹具归属实际测试或合同所有者；未来可能使用的样例不作为当前配置保存。
文档引用或目标架构描述不构成消费者。删除配置以 Git 历史保留，不建立 archive 或兼容跳转。

合同型 JSON 的唯一注册入口是 `packages/contracts/schemas/contract-schema-registry.v1.json`，不另建
配置总表。配置变更只需要运行受影响的本地、合同和制品检查；部署或线上状态不属于默认完成条件。
