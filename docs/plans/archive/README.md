# Plans Archive

`plans/archive/` 保存已经退出 live workstream 入口的 plan 文档。
这些文档继续保留路径、closeout 说明、历史基线、supporting reference 或 supersession 关系，但不再承载当前执行真相。

## Completed

- `completed/README.md`

## Historical

- `historical/README.md`

## Superseded

- `superseded/README.md`

## Usage Rule

- 需要真正的 live entry 时，回到 `.planning/WORKSTREAMS.md` 与 `.planning/workstreams/<slug>/README.md`
- 需要完成态说明、旧方案基线或 supersession 关系时，再进入本 archive namespace
