# Ops Web 产品需求

## 文档边界

本文定义 Ops Web 的操作者任务、页面体验、权限表现和验收要求。系统职责见
`../architecture/system/ops-observability.md`，HTTP 语义见 `../contracts/ops-web/README.md`，Dining
内容规则见 `dining.md`。本文不固定组件库、数据库结构、供应商配置或部署参数。

## 产品定位

Ops Web 是受访问保护的运维和内容运营界面，面向值班人员、运行服务负责人和内容维护人员。
它帮助操作者判断系统状态、排查一次请求并完成少量明确准入的管理操作，不替代 Temporal、
Langfuse、Sentry、Axiom 等平台的完整界面。

浏览器只能获得完成当前任务所需的有界数据，不获得数据库、观测平台、密钥存储或下游管理
凭据。

## 操作者任务

### 查看运行概况

操作者可以选择预设时间范围，查看请求量、成功情况、耗时趋势、关键服务、Temporal 队列和
已配置观测信号的状态。

不同数据来源独立显示结果。无数据、查询失败、部分响应和使用旧缓存必须呈现为不同状态；单个
来源失败不能抹掉其他可用结果，也不能改写产品请求状态。

### 查找和排查请求

操作者可以按时间、状态、关键词和已知关联标识查找请求，使用可分享的 URL 保留筛选条件，并
通过游标继续浏览结果。

请求详情分别展示：

- 产品与执行摘要；
- 已保存的执行步骤和工具结果摘要；
- 当前请求可用的日志、调用链、错误摘要和外部系统入口。

页面支持复制关联标识。外部观测数据只提供诊断线索；失败、无记录或部分响应不能改变请求的
持久状态。

### 维护在线 Provider Config

操作者可以查看当前激活配置、角色完整性和验证结果，并可以创建不可变配置、
发起验证并原子激活完整配置；并发更新冲突必须明确提示，不能覆盖其他人的新版本。

密钥提交后立即从界面清空，后续只显示不可逆标识。服务身份不能进入 Ops Web。

### 替换门户认证

人员操作者可以查看固定门户凭据是否已配置、最近更新时间、维护任务状态和最近验证结果。页面
允许替换凭据并恢复固定维护任务，但不读取或显示当前凭据，也不提供通用 Secret 管理能力。

替换成功只表示新凭据已保存；页面必须分别显示维护任务是否恢复，不能把保存成功描述成门户
登录已经验证成功。

### 管理采集运行

操作者可以查看通知计划、当前离线发布和有界采集任务，按状态筛选任务并进入详情。失败或已
取消的独立任务可以重试；父工作流子任务不能脱离父工作流单独重试。

操作者可以暂停、恢复或立即核对固定通知计划，也可以按精确 ID 提交文件发布。页面不允许选择
任意 Temporal Schedule、Workflow ID、来源扫描范围或在线发布目标。

### 维护食堂内容

内容维护人员可以从来源运行和观测记录重建草稿，查看校验问题，发布不可变目录版本或回滚到
兼容版本，并处理评价的隐藏、恢复、重新绑定和复检。具体内容规则和验收由 `dining.md` 维护。

来源同步不会自动改变学生端内容。页面必须明确区分来源数据、当前草稿、已发布版本和评价
状态，危险操作需要清楚说明对象和结果。

## 信息结构

一级导航包含：

- 运行概览；
- 请求排查；
- Provider Config；
- 采集运行；
- 门户认证；
- 食堂内容。

请求详情提供“概览”“执行”“日志与调用链”三个视图。Ops Web 不提供通用日志搜索、数据库
浏览、任意外部查询或工作流控制台。

## 交互要求

- 桌面端支持高密度扫描；移动端将侧栏和宽表转换为可操作的纵向布局。
- 筛选、翻页、标签和表单支持键盘操作、可见焦点、加载和禁用状态。
- 状态同时使用文字和视觉提示，不能只依赖颜色。
- 刷新数据时保留仍有用的上一组结果，并标明其生成时间；失败不能伪装为空数据。
- 输入无效、权限不足、依赖不可用、并发冲突和操作成功使用不同反馈。
- 320、390 和 1440 像素宽度下不得出现页面级横向溢出、文本重叠或不可达控件。

## 数据与权限体验

- 页面不展示完整用户身份、原始对话、原始提示词、原始回答、记忆正文或检索正文。
- Cloudflare Access policy 决定获准人员，Ops Web 不维护按页面或操作拆分的第二套人员名单。
- 写操作必须执行同源和所属领域的输入、并发与幂等校验。
- 页面不能让浏览器选择任意查询语言、数据集、组织、项目、时间范围、字段投影或返回上限。
- 管理依赖不可用只影响对应页面，不应使仍可使用的请求排查页面失效。

## 非目标

- 修改、重跑或取消产品请求和工作流；
- 复制外部观测、工作流或评测平台的完整功能；
- 提供任意 SQL、日志查询、外部 API 代理或通用 Secret 管理；
- 镜像外部平台正文、模型 trace、评测数据集或人工标注状态；
- 在线登录学校门户或编辑任意 Temporal Schedule；
- 承担学生产品 API 或拆出没有独立所有权的第二个运维后端。

## 验收

- 六个一级页面和三个请求详情视图均可从导航到达并正确恢复 URL 状态。
- 运行概况分别展示请求、服务、Temporal 队列和已配置观测信号。
- 请求筛选、游标翻页、空状态、刷新失败和关联标识复制可用。
- 无数据、来源失败、部分响应、旧缓存和权限不足均有可区分的反馈。
- 获准人员可以完成 Provider Config、采集运行、门户认证和 Dining 的对应操作，其他身份只能看到其权限
  允许的内容。
- 浏览器不能获得服务端凭据或扩展服务端固定的数据访问范围。
- 所有接口错误保留错误状态，不改写为成功空数据或未说明的部分成功。
- 键盘、移动端和桌面端布局满足本文交互要求。
