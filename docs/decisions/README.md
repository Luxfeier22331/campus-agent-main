# 架构决策

本目录保存仍有解释价值的重要架构决策。`accepted` 表示当前接受；被取代或废弃且不再
承载唯一理由、迁移约束的 ADR 由 Git 历史保留，不在当前分支充当跳转页。

查找决策时按文件名主题或 `decision_id` 搜索，并先检查 frontmatter 生命周期。README 不
维护完整 ADR 清单，也不复制各 ADR 结论。

文档治理见 [ADR-0038](./adr-0038-documentation.md)。旧 ADR 不作为当前事实所有者；仍需
保留的替代关系必须在 frontmatter 或正文中显式说明。
