# 校历

`calendar/academic_calendar` 是人工核对的结构化参考数据，用于表达学期日期、教学周和已经确认的
课程调整。当前仓库只包含合成样例，没有产品发布任务、Campus Docs 索引输入或模型可见工具。

官网和通知采集可以提供候选材料，但页面日期、通知分类或模型推断都不能直接成为校历事实。
校历记录必须明确来源、适用学期、日期范围和调整关系。

在线回答不能扫描原始通知或让模型自行计算未发布的教学周。当前数据和 schema 位于
`configs/reference-data/calendar/academic_calendar/`；配置存在不表示校历能力已经开放。
