# 校历

`calendar/academic_calendar` 是人工核对的结构化数据概念，用于表达学期日期、教学周和已经确认的
课程调整。当前仓库没有该领域的发布任务、在线查询目标或模型可见工具，也不保存当前运行配置。
校历不属于 `campus-docs/source.json` 的文档发布范围，也不进入 Campus Docs 索引。

官网和通知采集可以提供候选材料，但页面日期、通知分类或模型推断都不能直接成为校历事实。
校历记录必须明确来源、适用学期、日期范围和调整关系。

在线回答不能扫描原始通知或让模型自行计算未发布的教学周。未来若建立消费者，数据和 schema
必须归属该消费者的合同或测试目录；目录存在本身不表示校历能力已经开放。
