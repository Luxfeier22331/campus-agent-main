# 目标架构

## 文档边界

本文只规定长期系统约束，不列举当前组件、接口字段、环境状态或实施步骤。当前实现见
所属系统、领域、合同和数据文档，具体技术选择及理由见决策笔记，可执行字段由代码、schema 和注册表
维护。

## 系统形态

产品请求与离线数据处理保持两条独立链路：

```text
产品界面 -> 产品后端 -> 持久执行 -> Agent 与获准工具 -> 产品终态
来源准入 -> 持久采集 -> 不可变产物 -> 已清洗消费输入 -> 不可变索引激活
```

两条链路可以通过已发布的读取模型连接，但在线请求不能直接触发来源采集，也不能把原始采集
产物当作已发布知识。

## 产品与执行

- 产品后端拥有账号、会话、对话传输、产品 API 和用户可见终态；
- 持久执行层拥有运行准入、重试、超时、取消和恢复，不扩张为第二个产品后端；
- 产品请求和用户可见终态不能依赖产品表与执行投影位于同一数据库；跨所有者消费者通过受控接口
  或明确的读取投影组合数据，不直接建立跨所有者 join；
- 产品后端只负责命令到达持久执行层之前的可靠交付。持久运行已经接纳后，其重试、超时、取消和
  恢复由唯一执行所有者和 Temporal 推进，产品后端不建立第二套执行状态机；
- 一次请求只有一个 Agent 工作流和一个持久执行所有者；工作流可以包含多次模型 operation，
  operation 内的模型与工具循环不另设持久执行所有者；
- 浏览器断开不会终止持久运行，恢复读取同一个运行记录；
- 终态处理只校验和持久化结果，不再次调用模型或重写回答；
- 页面、工具或领域只有具备独立数据、扩缩容或安全所有权时才拆分服务。

## Agent 与工具

- Primary Agent 在服务端准入的模型可见能力中决定回答、澄清、拒绝或调用工具；
- 工具注册必须同时具备稳定名称、schema、handler、权限边界、超时、结果投影和测试；
- 配置、schema 或代码存在不自动向模型开放能力；
- 浏览器和模型不能选择供应商、数据库查询、索引别名或其他基础设施参数；
- 在线模型目标和凭据由独立配置所有者维护；执行控制只冻结目标身份，不拥有配置管理、密钥或
  provider 路由；运行消费者必须以预期目标 hash 解析配置，不能静默 fallback；
- 工具自身负责领域输入校验和访问控制，外层不复制语义路由器；
- 默认回答不能绕过注册表使用现场采集、未准入远程工具或隐式搜索路径。

## 知识与记忆

- 机构知识通过显式发布、激活的不可变读取模型提供；同一运行的本地检索结果必须保持索引绑定一致，
  绑定时机与校验方式由[检索服务](./system/retrieval-serving.md#在线消费边界)维护；
- 原始来源、候选检索结果、最终证据和浏览器可见引用具有不同生命周期；
- 回答只能引用当前运行已校验并投影的证据；
- 个人记忆、机构知识和账号会话是三套独立事实；
- 记忆可以帮助跟进、偏好和消歧，但不能授予权限、开放工具或放宽证据要求；
- 内部存储标识、原始记忆载荷和检索后端参数不暴露给模型工具或学生界面。

## 数据与采集

- 每项事实只有一个写入所有者，其他组件读取投影或调用受控接口；
- 产品状态、执行投影和工作流历史必须可以独立迁移和保留，物理同库不得成为正确性条件；
- 小规模环境可以把产品、执行和平台数据库合并到同一受管 PostgreSQL 集群；是否拆分 database、
  schema、角色和迁移所有者由实际数据边界、权限和迁移需求决定，不按组件名称自动拆分。不得为
  减少逻辑边界而建立跨所有者 join；
- 大对象和不可变运行产物进入对象存储，关系数据库保存产品事实和有界读取模型；
- 工作流历史、模型 trace、原始来源和在线索引不复制进产品数据库；
- 来源事实、已清洗消费输入、索引和产品读模型分别管理生命周期；
- 采集入口使用所属 CLI 或 Job 合同，不把通用任务注册表作为所有采集的前提；
- 采集完成、在线索引激活和回答运行的索引绑定是不同动作，不能相互替代。

## 观测与评测

- 稳定关联标识和标准 trace context 贯穿产品入口、持久执行、模型与受控投影；
- 通用日志和错误平台只接收各自合同允许的受控字段；模型观测平台是否接收评测正文由具体评测
  输入和平台配置决定，生产 trace 不因此恢复正文采集；
- 产品数据库只保存有界运行摘要，不成为第二套 trace store；
- 评测输入由调用方提供；Langfuse 可以展示调用方按需发布的评分，但不作为输入来源或同步控制面；
- 质量评分用于分析和评审，不自动替代运行合同或形成发布结论；
- 不建设平行的观测平台、评测平台、标注队列或自研发布门禁。

## 交付

- 源码仓产出不可变镜像、按目标 Worker 配置生成的 Worker 候选版本、schema 和发布清单；
- 环境仓选择版本、流量、Secret、地址和平台配置；
- 应用运行时不自行部署基础设施，也不把某次部署状态写回长期源码文档；
- Secret 不进入 Git、镜像、ConfigMap、浏览器包、工作流载荷或观测正文；
- 本地运行、CI 构建和部署清单存在都不能代替真实环境状态。

## 禁止形态

- 产品后端内嵌第二套 Agent 循环、工作流 worker 或采集执行器；
- 在线查询直接读取原始对象存储产物或调用来源采集器；
- 关系数据库承担执行队列、工作流历史、原始模型 trace 或大对象存储；
- 通过兼容包装、静默成功或尽力恢复掩盖缺失合同和下游故障；
- 为未开放能力预建空工具、空服务、占位任务或无消费者数据结构。
