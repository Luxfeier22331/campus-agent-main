# v1.3 MUC Campus Q&A 前端设计说明

## 设计边界

本版按最新产品边界重做：问答助手是主体验；文档、校园地图、饭堂分布图、反馈是独立页面，但不做成 App 启动器。

## 页面结构

- `/`：首页 / 新会话，采用 ChatGPT-like 历史会话侧栏和主输入框。
- `/c/:conversationId`：对话线程，来源跟随每段回答底部展示，不设右侧“本次引用”。
- `/docs/...`：成熟文档站布局，左侧分类、中间正文、右侧本页目录。
- `/map`：校园地图，只承载 GeoJSON 地点标注。
- `/dining`：饭堂分布图，只承载饭堂 SVG 和名称价格列表。
- `/feedback`：全站唯一反馈入口。

## 本版关键修正

1. 校园地图与饭堂分布图解耦，不再通过“地图 / 平面图”切换表达。
2. 饭堂 SVG 只展示档口位置和布局结构，不在图中展示菜品。
3. 名称与价格列表固定放在 SVG 下方，展示名称、价格、位置。
4. 删除“本层标注”命名，不使用“今日菜品 / 当前供应”等实时承诺文案。
5. 地图和饭堂页面均不使用右侧详情栏；选中状态使用浮层或高亮反馈。
6. 反馈入口全局唯一，页面可自动携带上下文。

## 视觉原则

- 少色彩、强结构。
- 使用学校身份色与交互色，界面主体保持黑白灰蓝。
- 文档站模仿成熟 docs 产品，避免资料库/详情页重叠。
- 问答页像对话产品，地图页像地图，饭堂页像分布图查看器。

## 占位说明

原型中的校徽、地图、饭堂 SVG、名称和价格均为设计稿占位。正式实现时应替换为授权标识、真实 GeoJSON、真实手绘 SVG 和真实整理数据。
